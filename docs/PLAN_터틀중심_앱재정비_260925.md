# 터틀 중심 앱 재정비 계획서 (2026-09-25)

> 상태: **2026-09-26 사용자 승인.** P0부터 착수(승인 게이트: P1 저장구조·P2 머니경로·P4 외부발송은 각 착수 전 재확인).
> 이 계획은 2026-09-25 사용자와 6차례 문답 + 조사 3건 + 검증 3건(1차·금은 재검증·2차)으로 만들었다.
> 투자자문이 아니다. 모든 검증 수치는 과거 데이터 기준이며 미래를 보장하지 않는다.

## 0. 한눈에 보기 (쉬운 말)

**지금 문제**: 앱에 기능은 많은데 실제로는 '수익 통계'만 본다. 카톡 알림은 연결돼 있지만 종목마다 계획을 손으로 입력해야 해서 내용이 비어 있다. 손실 종목은 판단 기준이 없고, 팔 결심이 안 서고, 화면이 복잡해서 정리하지 못했다.

**바꾸는 방향**: 앱을 **터틀 규칙 하나로 단순하게** 만든다.

```
보유종목 ── 앱이 매일 선을 자동 계산 (입력할 것 없음)
   │
   ├─ 종가가 20일 최저가 아래 → 카톡 "팔 때"  → 팔고 기록하면 자동으로 '다시 살 때 감시'
   │
   └─ 감시 종목이 55일 신고가 돌파 → 카톡 "다시 살 때"
            └─ 앱이 살 수량·손절가(증권사 예약용)·추가 매수 가격을 계산해 보여줌
               → 오를 때마다 최대 4번 나눠 삼(불타기), 손절선도 같이 올라감
```

- 앱은 **계산하고 알려 주기만** 한다. 주문은 사용자가 증권사 앱에서 직접 하고, 앱에 기록한다(자동 주문 없음).
- 카톡은 **장 마감 후 1번 + 아침 요약 1번**.
- 더보기에는 **수익 통계·터틀 정리·설정**만 남긴다. 나머지 신호와 팝업은 숨긴다(삭제하지 않는다).

**미리 알아야 할 대가**: 검증 결과 터틀은 **"돈을 더 버는 도구"가 아니라 "큰 손실을 막는 도구"**다. 선택하신 설정의 과거 성적은 **최대 하락폭 약 −20%**(그냥 보유는 −28~31%)였다. 대신 **최종 자산은 그냥 보유의 약 70~82%**였다(§3.3). 다만 2023년 이후 시작한 경우와, 사용자가 실제로 산 날짜 기준으로는 터틀이 더 나은 경우가 많았다.

## 3. 터틀 규칙 기본값

### 3.1 기본값 표 (원조 터틀 기준 + 필수 조정 1개)

| 항목 | 기본값 | 원조 그대로 / 조정 | 설정 변경 |
|---|---|---|---|
| 다시 살 때(진입) | 종가가 **직전 55일 최고가**를 넘으면(당일 제외) | 원조 System 2 | 20/55/100일 |
| 팔 때(청산) | 종가가 **직전 20일 최저가** 아래(당일 제외) | 원조 System 2. 최신 조사도 "20일 기본 유지"를 추천. 변동폭 추적선(ATR 3N)은 검증에서 수익이 가장 낮아 기본값에서 제외 | 20일 최저 / 10일 최저 / 55일 최저 / 50일 이동평균 / ATR 추적선 |
| 손절 (다시 산 종목) | 마지막 매수 체결가 − **2N** → 증권사 예약 손절 | 원조 | 1.5~3N |
| 손절 (원래 보유분) | 없음. 청산선만 적용(매수 시점의 N을 모르므로) | 불가피한 조정 | — |
| N (평균 하루 변동폭) | 20일 ATR (`computeN`) | 원조와 실질적으로 같음 | — |
| 1유닛 크기 | **터틀 관리 자산 × 1% ÷ N** 과 **종목 한도 ÷ 4** 중 작은 값 | 원조 공식 + 조정 | 위험 0.25~1% |
| 불타기 | 마지막 체결가 + **2R**(= 손절 폭 2N의 2배 = 4N)마다 1유닛, **최대 4유닛**, 추가할 때마다 손절선 상향 | **조정(강의식)** — 원조 ½N보다 MDD·Calmar 우세(2차 검증 루카스 비교 절) | 간격 2R / ½N / 직접 입력 · 추가 금액 1배 / 0.5배 · 최대 1~4유닛 |

### 3.2 8.5억 원 기준 예시 (종목 한도 10% = 8,500만 원, 유닛당 최대 2,125만 원)

| 종목 성격 | N/가격 | 원조 공식 금액 | 실제 1유닛 | 2N 손절 시 손실 |
|---|---|---|---|---|
| 잔잔한 종목 (금·채권 ETF급) | 1.5% | 5억 6,700만 원 | **2,125만 원** (한도) | 약 64만 원 |
| 국내 개별주 평균 | 3% | 2억 8,300만 원 | **2,125만 원** (한도) | 약 128만 원 |
| 코인급 | 6% | 1억 4,200만 원 | **2,125만 원** (한도) | 약 255만 원 |

→ 빌린 돈 없이 여러 종목을 가진 계좌에서는 **실제 금액을 원조 공식이 아니라 종목 한도가 정한다.** 한도를 바꾸면 매수 금액도 바로 바뀐다.

### 3.3 이 설정의 과거 검증 성적 (2차 검증 W1G / W1G_DD, 2016~2025 시작 12개)

| | 그냥 보유 | 선택하신 설정 | 참고: 검증상 가장 균형이 좋았던 조합 |
|---|---|---|---|
| 연수익 중앙값 | 19.8~24.7% | 13.4~15.5% | 14.2~15.3% |
| 최대 하락폭 | −27.5~−31% | **약 −20~21%** | 약 −16.7% |
| 최종 자산 (그냥 보유 = 1) | 1 | 0.70~0.82 | 0.78~0.99 |

- 범위의 두 끝은 각각 초기 비중을 지금 비중으로 둔 경우와 균등 비중으로 둔 경우다.
- '가장 균형이 좋았던 조합'은 50일 이동평균 청산에, 금·은·채권·지수 ETF를 터틀에서 뺀 것이다. 결과를 본 뒤 고른 조합이라 참고용이며, **설정에서 언제든 이쪽으로 바꿀 수 있다.**
- 금·은 재검증에서는 2026년 1월 고점 이후 급락 때 터틀이 방어했다(은: 고점 대비 남은 가치 그냥 보유 0.55, 터틀 0.64).
- 사용자가 실제로 산 날짜부터 계산하면 **약 68% 종목에서 터틀이 더 나았다**(매수일 기록의 정확도에는 한계가 있음).

## 4. 무엇이 바뀌나 (화면·카톡)

### 4.1 홈: "터틀 오늘 할 일"이 맨 위
- 네 칸: **팔 때**(청산선 아래로 마감) · **다시 살 때**(55일 돌파) · **추가 매수**(불타기 가격 도달) · **손절선 확인**(예약주문 점검).
- 각 줄에 "왜 떴는지" 한 줄. 예: "20일 최저가 51,200원 아래로 마감 (종가 50,800원)".
- 0건이면 "오늘 할 일 없음 — 규칙상 보유 유지"를 보여 준다(빈 화면 금지).
- 대기 자금(파킹) 금액과 계좌 축소 적용 여부를 표시한다.

### 4.2 '터틀 정리' 화면 (기존 '대청소'를 대체)
- 지금 청산선 아래에 있는 종목 목록. 1차 검증 시점 기준(일부 종목은 7월 자료)으로는 83종목 중 약 5개였다. 시세를 갱신하면 달라진다.
- **작은 종목(총자산 1% 미만)은 체크해서 한꺼번에**, 큰 종목은 하나씩 결정한다.
- 결정 버튼은 두 가지다: [팔았음 기록] 또는 [이번엔 보류 + 사유]. 보류가 쌓이면 "규칙과 다르게 N번 보류" 경고를 띄운다.
- 해외주식은 기존 세금 참고 패널을 재사용한다. "올해 해외 이익과 통산되어 세금이 약 X원 줄어듦"을 **참고용**으로 보여 준다.
- 팔았음을 기록하면 그 종목이 자동으로 **'다시 살 때 감시 명단'**에 들어간다. 사용자가 누른 버튼에 동반되는 저장이므로 보이지 않는 쓰기가 아니다.

### 4.3 재매수 계산기
- '다시 살 때' 알림을 누르면 한 화면에 네 가지를 보여 준다: **① 살 수량·금액(1유닛) ② 증권사에 걸 손절가 ③ 다음 추가 매수 가격(+½N) ④ 계산 근거(N, 한도, 계좌 축소 여부)**.
- [샀음 기록]을 누르면 매수 기록과 터틀 유닛 기록이 함께 저장된다. 추가 매수 때도 같은 방식이고, 손절가가 자동으로 올라간다.
- 현금이 부족하거나 5만 원 미만이면 사유를 표시한다.

### 4.4 보유자산 표
- 열 추가: **청산선까지 거리(%) · 상태(보유 유지 / 팔 때 / 감시 중 / 재매수 N유닛)**.
- 기존 표 설정은 유지하고, 새 열은 켜고 끌 수 있다.

### 4.5 카톡
- **시장별 마감 후 1번**: 한국은 오후 4시쯤, 미국은 다음 날 아침 7시쯤, 코인은 UTC 일봉 마감 후. 보내는 내용은 팔 때·다시 살 때·추가 매수·(재매수분) 손절가 이탈 확인이다.
- **아침 요약 1번**: 오늘 할 일 목록과 대기 자금.
- 사용자가 표시한 관심종목의 55일 돌파도 함께 보낸다.
- 하루 상한은 기존 GAS 상한(8건)을 유지하고, 넘치면 요약으로 묶는다. 2주 관찰 후 조정한다.
- 종목별 선은 앱이 계산해 GAS로 넘기고(매니페스트), GAS는 확정 종가와 선만 비교한다.

### 4.6 메뉴·신호 정리 (숨김 = 코드 보존, 설정에서 되살릴 수 있음)
- 더보기: **수익 통계 · 터틀 정리 · 설정**만 남긴다.
- 숨김: 연구실·신호 리플레이, 투자 가이드, AI 어시스턴트, 매매 계획 세우기.
- 숨김: 알림 브리핑 자동 팝업, 구루 신호 카드, 과열(리스크 매트릭스), 기존 매도 경보. 계산은 그대로 두고 표시만 끈다. 급성 매도 6종(KR_*) 같은 검증된 규칙은 **삭제 금지**.
- 기존 '매매 계획(TradePlan)'은 새 화면에서 뺀다. 이미 걸린 계획이 있으면 그대로 동작한다.

### 4.7 설정: '터틀 규칙' 섹션
- §3.1 표의 모든 값을 보여 주고 바꿀 수 있게 한다. 기본값 옆에 **'원조'** 또는 **'조정'** 배지를 붙인다.
- 값을 바꾸면 그 값의 과거 검증 성적을 한 줄로 보여 준다(검증 보고서의 수치). 너무 짧은 청산선(10일 미만 등)에는 경고를 띄운다.
- [원조 기본값으로 되돌리기] 버튼.
- 적용 범위: 종목별·자산군별 "터틀 제외" 토글. 가족 계정은 기본으로 제외.

## 5. 안전 원칙 (바꾸지 않는 것)

1. **자동 주문 없음**: 기존 터틀 주문 엔진(`types/turtleLock.ts` OBSERVE_ONLY)은 잠금을 유지한다. 알려진 결함 ①~⑤와 D-2가 아직 코드에 남아 있어서(조사 문서 §g에서 직접 확인) 그 경로는 쓰지 않는다. 새 기능은 **관찰 전용 패턴(`utils/todayTurtle.ts`)을 확장하는 방식**으로 만든다.
2. **보이지 않는 쓰기 금지**: 저장은 사용자가 누른 버튼(팔았음/샀음/보류/설정 저장)과 함께일 때만 한다.
3. **저장 경로 단일화**: `commitPortfolio(patch)`만 쓴다. 새 필드는 기존 도메인(`turtleSettings`·`watchlist`·`turtlePositions`) 안의 optional 필드로 넣는다. 새 최상위 저장 도메인이 필요해지면 **따로 승인을 받는다**.
4. **순수 계산은 utils + 골든 테스트**: 앱과 GAS가 같은 순수 함수를 공유한다(파리티). 백테스트 엔진(`scripts/backtest/portfolioTurtle/{exitRules,sizing}.ts`)과 같은 입력이면 같은 선·수량이 나와야 한다.
5. **신선도**: 오래된 시세로는 '다시 살 때'·'추가 매수'를 보류하고 "시세 갱신 필요"를 표시한다(기존 신선도 게이트 재사용).

## 6. 단계별 구현 (각 단계: Sonnet 워커 구현 → Advisor 검증 → 사용자 확인·커밋)

| 단계 | 내용 | 완료 기준 | 승인 |
|---|---|---|---|
| **P0 엔진** | 순수 모듈(가칭 `utils/turtleHoldings.ts`): 청산선 5방식·재진입·유닛 크기(min(1%/N, 한도÷4))·½N 불타기 가격·손절 상향·계좌 축소·비례 축소·5만 원 생략·적용 범위 판정. `TurtleSettings` 확장(청산 방식, 기준 자산 전환, 범위 제외 — 옛 저장본은 `{...DEFAULT, ...loaded}` 병합). **`utils/todayTurtle.ts`의 55/20 하드코딩을 설정값으로 교체**. 백테스트 엔진과의 파리티 골든. 전체 위험 한도 24% vs 12% 차이를 백테스트로 확인 | 골든 테스트 + `npm test` 그린 | 계획 승인으로 착수 |

| **P4 카톡** | `notifyManifest`에 터틀 선·관심종목 추가, GAS `closeCheck`/`morningDigest` 확장, 문구("왜" 한 줄), 하루 상한·묶음 | 매니페스트 파리티 + GAS 빌드 | **외부 발송 변경 전 확인** → 사용자가 `npm run gas:push` |

## 7. 알려진 위험과 한계

- **수익이 줄 수 있다**: 과거 검증 기준으로 최종 자산이 그냥 보유의 약 70~82%다. 목적은 큰 손실 방지다.
- **휩쏘**: 팔았다가 곧 다시 사는 일이 생긴다. 1차 검증 중앙값은 종목당 약 1회였다. 매매마다 비용과 세금이 붙는다. 2026년부터 코스피·코스닥 매도세는 0.20%, 금·은·채권 ETF 매매차익에는 15.4%가 붙는다.
- **금·은·채권 ETF**: 전부 적용을 선택했지만 검증상으로는 제외하는 편이 나았다. 설정에서 바꿀 수 있다.
- **검증의 편향**: 현재 보유 종목만 봤고(생존 편향), 과거 비중은 가상이며, 세금 통산은 반영하지 않았다.
- **데이터**: 무료 시세 기반이라 일부 종목이 늦게 갱신될 수 있다. 오래된 시세면 판단을 보류한다.
- **GAS 카톡**: 트리거 정밀도가 ±15분이고, 카카오 토큰 갱신에 의존한다. 기존 운영 방식과 같다.
- **규칙을 지키는 일**은 결국 사람이 한다. 보류 누적 경고와 결정 기록이 그 장치다.

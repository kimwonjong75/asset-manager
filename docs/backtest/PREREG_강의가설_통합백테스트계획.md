# 외부 강의 가설 통합 백테스트 계획

- 작성일: 2026-07-25
- 상태: `DRAFT_PRELOCK`
- 목적: 외부 강의의 주장, 기존 Codex 검토, `CANDIDATES_강의검토_260725.md`를 통합해 앱 적용 전 검증 순서·정의·채택 기준을 고정한다.
- 현재 단계: 방법론 계획. 아직 설정 JSON과 SHA-256이 생성되지 않았으므로 **사전등록 완료 또는 결과 확정 문서가 아니다.**

---

## 1. 최종 결론

가장 효율적인 순서는 다음과 같다.

1. 공용 일봉 이벤트 스터디 하네스와 데이터 게이트를 먼저 만든다.
2. **1차 배치**로 한국 시장 레짐과 한국 급성 매도 신호를 함께 검증한다.
3. **2차 배치**로 보유 중 열화 경고를 검증한다.
4. **3차 배치**로 한국 RS 90 진입 품질을 오프라인 검증한다.
5. 런치패드 규칙은 낮은 구현비를 이용해 별도 단일가설로 검증한다.
6. 동적자산배분은 정확한 자산 목록과 정책 정의를 받은 뒤 독립 전략으로 검증한다.
7. 미국 개별주 가설은 point-in-time 유니버스와 상장폐지 포함 시계열이 확보될 때까지 보류한다.
8. 모든 한국 개별주 결과는 시장·시가총액·유동성·거래량·변동성·사전 상승률·1일 충격으로 같은 형식의 분해표를 추가한다.

이 계획의 핵심은 **상관관계 확인 → 거래 반사실 비교 → 포트폴리오 검증 → 앱 그림자 운영**의 네 단계를 건너뛰지 않는 것이다. 역사적 이벤트 스터디가 유의하다는 이유만으로 자동매도나 자산배분 변경을 허용하지 않는다.

## 2. 두 검토를 합친 최종 판정

| 후보 | 검증 가능성 | 현재 앱 적용성 | 최종 우선순위 | 최종 판정 |
|---|---:|---:|---:|---|
| 한국 시장 MA150 레짐 | 높음 | 높음 | 1차 배치 | 신규 진입 게이트를 주가설로 검증 |
| 한국 급성 매도 신호 6종 | 높음 | 높음 | 1차 배치 | 경고 신호로 검증, 자동매도 금지 |
| 보유 중 열화 경고 | 높음 | 높음 | 2차 배치 | RS 불필요 항목부터 검증 |
| 한국 RS 90 진입 품질 | 높음 | 낮음 | 3차 배치 | 오프라인 연구 우선, 런타임 구현은 별도 승인 |
| 런치패드/MA 수렴 돌파 | 높음 | 높음 | 보조 트랙 | 앱의 기존 지표를 살릴 단일가설로 검증 |
| 동적자산배분 | 조건부 높음 | 조건부 | 독립 트랙 | 자산 목록·현금·리밸런싱 정의 전에는 동결 불가 |
| 미국 개별주 RS·저가주·거래량 | 낮음 | 낮음 | 보류 | 미국 point-in-time 데이터 확보 전 검증 금지 |
| 개별기업 저평가·단일종목 사례 | 낮음 | 낮음 | 제외 | 재무 데이터와 일반화 가능한 표본이 없음 |

### 강의 변수별 포함 상태 재검토

| 강의 비교·변수 | 현재 계획의 상태 | 보강 후 처리 |
|---|---|---|
| 한국 vs 미국 | 한국은 실행 가능, 미국은 데이터 미확보 | 현재 결론은 한국에만 한정. 미국 데이터 게이트 통과 후 같은 정의·비용·기간으로 별도 재현하고 국가 간 상호작용을 검정 |
| 대형주 vs 소형주 | RS 품질의 Q5와 매칭 변수에는 포함, 공통 결과표에는 부분 포함 | 직전 월말 point-in-time 시총으로 대형·중형·소형을 고정하고 모든 주요 가설에 분해표·상호작용 검정 추가 |
| 거래량 | 급성 신호·RS 품질·런치패드에 포함 | 당일 거래량/직전 20일 평균 거래량 배수를 공통 팩터로 추가 |
| 거래대금·유동성 | 주분석 필터와 매칭에 포함 | 직전 20일 평균 거래대금 분위별 결과와 3억·10억·30억 원 민감도 결과를 분리 보고 |
| 변동성 | 매칭·보유 열화·RS 품질에 포함 | 직전 20일·63일 실현변동성 분위별 결과를 모든 주요 가설에 추가 |
| 상승률·모멘텀 | 급등 신호와 RS 품질에 포함 | 사전 5일·21일·63일 수익률과 강의 임계값을 공통 팩터로 추가 |
| 시가총액 | 매칭·RS 품질에 포함 | 월말 point-in-time 백분위와 대형/중형/소형 구간을 모두 저장 |
| 1일 변동성 | 급락·상한가 신호에는 포함, 독립 축은 불명확 | 부호 있는 1일 수익률과 절댓값 충격을 구분해 저장·보고 |
| MA·RS·윗꼬리·붐버스트 | 개별 가설에 포함 | 기존 정의 유지. 진입 전 정보와 보유 후 정보를 계속 분리 |

따라서 “강의 내용이 모두 현재 백테스트에 포함됐다”라고 표현하지 않는다. 정확한 상태는 **한국은 주요 가격·수급·크기 변수가 포함되며 이번 보강으로 공통 분해까지 수행하고, 미국은 데이터 게이트 통과 전 미검증**이다.

### 기존 대형주 백테스트와의 경계

`PRELOCK_RESULTS_KR_SIZE.md`에는 “대형주는 20일 채널, 기타주는 55일 채널이 유리한가”라는 별도 가설의 검증 결과가 있으며 방향은 사전가설과 반대였다. 이 결과는 **규칙의 효과가 시총 구간에서 뒤집힐 수 있다는 사전 경고**로만 사용한다.

- 해당 결과는 이번 강의의 RS 품질 Q5 또는 급성 신호 효과를 입증하지 않는다.
- 이번 연구의 임계값·가설 방향을 그 결과에 맞춰 바꾸지 않는다.
- 동일 데이터가 일부 겹치므로 독립 재현으로 표현하지 않는다.
- 이번 결과가 특정 시총 구간에서만 나타나면 전체 시장 규칙과 구간 전용 규칙을 구분한다.

### 두 검토에서 수정한 부분

1. **시장 레짐과 급성 매도 신호를 경쟁시키지 않는다.**  
   둘 다 같은 일봉 하네스를 공유하고 구현비가 낮다. 시장 레짐은 시장 전체 위험을, 급성 신호는 개별 종목 위험을 다루므로 1차 실행 배치에서 함께 검증한다.

2. **`RS 90→97 급등`은 진입 필터가 아니다.**  
   RS 90 진입 뒤에만 관측되는 정보이므로 진입 시점 필터에 사용하면 룩어헤드다. 보유 중 열화 경고로 이동한다.

3. **`매수 후 +20% 급등`도 진입 필터가 아니다.**  
   매수 후 정보이므로 보유 중 경고로만 검증한다. “+20%”의 기간 정의가 강의에서 불명확하므로 5일·21일 두 정의를 미리 등록하고 같은 패밀리에서 보정한다.

4. **급성 신호가 유의해도 바로 자동매도하지 않는다.**  
   최초 적용 단계는 경고 배지 또는 검토 큐다. 자동매도는 최소 6개월 그림자 운영과 별도 사용자 승인을 통과해야 한다.

5. **동적자산배분은 기존 엔진 재사용 가능성과 전략 정의 완결성을 구분한다.**  
   엔진이 있어도 강의의 채권 ETF 8종, 정적 비중, 현금 대체자산, 리밸런싱 규칙이 확정되지 않으면 원가설 백테스트가 아니다.

## 4. 공통 데이터와 표본

### 4.1 한국 주식 유니버스

- KOSPI·KOSDAQ 보통주
- point-in-time 월말 유니버스 사용
- 상장폐지·소멸 종목 포함
- ETF·ETN·KONEX·SPAC·우선주 제외
- 기업행위 조정이 해결되지 않은 종목·기간은 제외 사유와 건수를 보고
- 월말 유니버스는 다음 달 첫 거래일부터 효력을 갖는다
- 미래 시총·미래 상장 상태를 과거 날짜에 소급 사용하지 않는다

현재 우선주 휴리스틱은 과대 제외 가능성이 있으므로, 실행 전 거래소 종목구분 필드와 대조한 별도 QA가 필수다.

### 4.2 표본 분할

| 구간 | 기간 | 용도 |
|---|---|---|
| 개발 | 2010-01-01~2019-12-31 | 구현 검증, 후보 특성 스크리닝 |
| 검증 | 2020-01-01~2022-12-31 | 단 한 번의 확인 검정 |
| 잠금 | 2023-01-01~2025-12-31 | 최종 확인, 현재 봉인 |

잠금표본은 다음 두 게이트가 통과할 때까지 실행하지 않는다.

- G8: 정상폐지·합병·자진상폐 대가 처리
- G11: KRX 공식 데이터 교차검증

### 4.3 가격과 체결

- 신호 계산: 거래일 `D` 종가까지의 정보만 사용
- 주문 가정: `D+1`의 다음 유효 거래일 시가
- 같은 봉의 종가 신호를 같은 봉 가격으로 체결 금지
- 가격 비교·기술지표는 분할조정 원화 가격을 동일 기준으로 사용
- 기존 `apply_corporate_actions.py`가 생성한 `adj_factor`, `adj_open`, `adj_high`, `adj_low`, `adj_close`, `adj_volume`을 재사용
- 신규 구현이 아니라 실행 시작 시 `npm run test:kr-size` 재통과와 매니페스트 G7·G10 통과를 확인
- 현재 실측 기준 기업행위 2,673건 중 미분류 185건(6.9%), 영향 종목 168개가 전 기간 투자대상에서 제외되어 있다. 신규 강의 하네스에서도 이 제외가 유지되지 않으면 즉시 중단
- 거래정지·시가 누락 시 사전등록된 다음 유효 시가 규칙 적용
- 포트폴리오 결과는 저장소의 한국 세금·거래비용 스케줄을 적용
- 이벤트 스터디의 무비용 효과와 포트폴리오의 비용 차감 효과를 분리 보고
- 현금배당이 반영되지 않은 가격수익률은 `PRICE_RETURN_EX_DIVIDEND`로 표시. 배당 포함 총수익 자료가 없으면 126일·252일 결과는 채택 근거가 아니라 조건부 증거로 취급

### 4.4 유동성

주분석 유니버스는 직전 20거래일 일평균 거래대금 10억 원 이상으로 한다. 민감도 분석은 3억 원과 30억 원을 사용하되 주결론을 바꾸는 임계값 탐색에 사용하지 않는다.

marcap 원본 parquet에 존재하는 원천 `Amount`를 처리 JSON에 재인제스트해 사용한다. `Amount`는 실제 당일 거래대금이므로 분할조정하지 않는다.

- `apply_corporate_actions.py`의 입력 컬럼과 처리 바 스키마에 `Amount`/`amount`를 추가하고 3,858개 종목을 재생성한다.
- 매니페스트에 `amount` 결측률·음수·원천 대비 일치 검사를 추가한다.
- S5와 10억 원 유동성 주분석은 원천 `amount`가 준비되기 전에는 실행하지 않는다.
- `adj_close × adj_volume`은 원천 `amount` 장애를 찾는 QA 비교값일 뿐, 주분석 거래대금으로 사용하지 않는다.

## 5. 공통 연구 설계

### 5.1 네 단계

| 단계 | 질문 | 산출물 | 앱 변경 허용 |
|---|---|---|---|
| 1. 이벤트 스터디 | 신호 뒤 성과·위험이 실제로 달라지는가 | 전방수익, MAE/MFE, 매칭 차이 | 없음 |
| 2. 거래 반사실 | 다음 시가 행동이 보유보다 나았는가 | 매도·진입 게이트의 순효과 | 없음 |
| 3. 포트폴리오 | 비용·중복·현금비중까지 포함해 개선되는가 | CAGR, MDD, Sharpe, turnover | 없음 |
| 4. 그림자 운영 | 실제 데이터에서 경고가 안정적으로 생성되는가 | 누락률, 오경보율, 실행 부담 | 경고만 가능 |

### 5.2 전방 성과

- 20거래일
- 63거래일
- 126거래일
- 252거래일

모든 기간을 보고하되 가설별 주평가지표는 하나만 지정한다.

- 급성 매도·보유 열화: **63거래일 시장초과수익률**
- 시장 레짐 신규 진입 게이트: **126거래일 포트폴리오 순초과수익률**
- RS 진입 품질: **126거래일 시장초과수익률**
- 런치패드: **126거래일 시장초과수익률**

위험 지표:

- 최대불리폭(MAE)
- 최대유리폭(MFE)
- 전방 구간의 10% 하위수익률

### 5.6 필수 공통 팩터 패널

모든 한국 개별주 이벤트는 신호일 `D`에 알 수 있거나 사전에 고정된 다음 값을 함께 저장한다. 구간 정의에 미래 수익률을 사용하지 않는다.

| 축 | 고정 정의 | 기본 보고 구간 |
|---|---|---|
| 시장 | 신호일 유효 시장 구분 | KOSPI / KOSDAQ |
| 시가총액 | `D`에 유효한 직전 월말 point-in-time 시총 백분위 | 대형 상위 20% / 중형 20~80% / 소형 하위 20% |
| 유동성 | `D-20`~`D-1` 평균 거래대금 | 적격 유니버스 내 하·중·상 3분위 |
| 거래량 과다 | `adj_volume[D] / mean(adj_volume[D-20:D-1])` | `<1배` / `1~2배` / `2~5배` / `5배 이상` |
| 단기 상승률 | 분할조정 종가의 사전 수익률 | `R5`, `R21`, `R63` 각각 3분위 및 강의 임계값 |
| 1일 방향 | `adj_close[D]/adj_close[D-1]-1` | `<=-10%`, `-10~-5%`, `-5~5%`, `5~10%`, `>=10%` |
| 1일 충격 | `abs(adj_close[D]/adj_close[D-1]-1)` | `<3%`, `3~5%`, `5~10%`, `>=10%` |
| 실현변동성 | `D-20`~`D-1`, `D-63`~`D-1` 일간수익률 표준편차 × `sqrt(252)` | 각 하·중·상 3분위 |
| 시장 레짐 | KOSPI MA150 위/아래 | 정상 / 위험 |

`1일 변동성`은 문맥상 모호하므로 두 값을 혼용하지 않는다. 방향이 있는 값은 **1일 수익률**, 방향을 제거한 크기는 **1일 절대충격**으로 명명한다.

거래량 관련 S4·S6·Q6 및 공통 팩터는 모두 `adj_volume`을 사용한다. 원시 `volume`은 분할 경계에서 기계적으로 급증할 수 있으므로 신호 계산에 사용하지 않는다.

각 주요 가설의 결과 파일은 최소한 다음 열을 같은 스키마로 출력한다.

- 구간명, 이벤트 수, 고유 종목 수, 연도 수

- 시장초과수익률 차이와 95% CI
- MAE, MFE, 10% 하위수익률
- 매칭 성공률과 결측률
- 비용 차감 거래 반사실

### 5.7 이질성 해석과 다중검정 규율

- 전체 표본의 주가설이 1차이며, 5.6절 분해표는 강건성 및 효과 이질성 확인이다.

## 6. 1차 배치 A — 한국 시장 레짐

### 6.1 주가설

`KOSPI 종가 < KOSPI MA150`인 날의 신규 진입은 그렇지 않은 날보다 향후 126거래일 순성과가 낮다.

주분석 지수는 앱이 수신하는 KOSPI 종가지수 시계열을 사용한다. 같은 날짜의 구성종목 단순 동일가중 수익률은 데이터 소스 이상을 찾는 강건성 비교로만 쓰고, 둘 중 결과가 좋은 쪽을 선택하지 않는다.

### 6.2 고정 변형

| 코드 | 정의 | 역할 |
|---|---|---|
| `KR150_LEVEL` | 종가 < MA150 | 주가설 |
| `KR150_SLOPE` | MA150 − MA150[20] < 0 | 보조 |
| `KR150_COMBINED` | LEVEL 또는 SLOPE | 보조 |
| `KR200_LEVEL` | 종가 < MA200 | 비교 기준 |

“150일선이 200일선보다 낫다”는 주장은 동일 진입 집합에서 `KR150_LEVEL`과 `KR200_LEVEL`의 순성과·MDD를 직접 비교해 판단한다. 여러 MA 기간을 추가 탐색하지 않는다.

### 6.3 두 개의 적용 반사실

1. **신규 진입 차단**: 위험 레짐에는 새 매수를 현금으로 보류
2. **신규 진입 반감**: 위험 레짐에는 목표 신규 비중의 50%만 진입

전량 매도는 테스트 결과표에는 참고 시나리오로도 넣지 않는다. 이 계획의 의사결정 범위를 넘어선다.

### 6.4 채택 기준

검증표본에서 다음을 모두 만족해야 경고 또는 신규 진입 게이트 후보가 된다.

- `KR150_LEVEL`의 126일 진입 성과 차이가 가설 방향과 일치
- Holm 조정이 필요한 보조 비교와 분리된 주가설 95% CI가 0을 넘지 않음
- 신규 진입 차단 또는 반감 포트폴리오가 순 Sharpe를 0.10 이상 개선하거나 MDD를 2%p 이상 개선
- 개선을 위해 연환산 CAGR을 1%p 넘게 희생하지 않음
- 상위 기여 연도 제거 후 방향 유지

통과해도 1차 앱 적용은 **시장 위험 배지와 신규 진입 경고**다.

## 7. 1차 배치 B — 한국 급성 매도 신호

### 7.1 고정 신호 정의

모든 이동 계산은 현재일 이전 값만 기준선에 사용한다.

| 코드 | 정의 |
|---|---|
| `S1_RUNUP_21D_100` | `close[D] / close[D-21] - 1 >= 1.00` |
| `S2_RUNUP_5D_40` | `close[D] / close[D-5] - 1 >= 0.40` |
| `S3_LIMIT_UP` | 2015-06-15 이전 14.5% 이상, 이후 29.5% 이상 상승하고 종가가 고가인 날. 기업행위일 제외 |
| `S4_GAP_BEAR_VOLUME` | `open[D]/close[D-1]-1 >= 5%`, `close[D] < open[D]`, 거래량이 직전 20일 평균의 2배 이상 |
| `S5_CRASH_10_MAX_AMOUNT` | 일간 수익률 `<= -10%`이며 당일 거래대금이 최근 63일 최대 |
| `S6_CRASH_5_VOLUME_2X` | 일간 수익률 `<= -5%`이며 거래량이 직전 20일 평균의 2배 이상 |

`S3_LIMIT_UP`은 실제 호가단위별 상한가 가격을 완전 복원한 값이 아니라 조정 OHLC 기반 판정이다. 허용오차 결과는 민감도 분석으로 보고한다.

### 7.2 주가설

각 신호 발생 후 63거래일 시장초과수익률의 중앙값이 매칭 대조군보다 낮다.

신호 6개를 하나의 가설 패밀리로 묶어 Holm 보정한다.

### 7.3 거래 반사실

- A: `D+1` 시가 매도 후 현금 유지
- B: 63거래일 보유
- C: 앱의 기존 매도 규칙만 적용
- D: 기존 규칙에 해당 신규 신호를 경고 우선순위로 추가

주된 경제적 비교는 C 대 D다. A 대 B는 신호의 순수 타이밍 효과를 보여주는 참고 비교다.

### 7.4 채택 기준

개별 신호가 보유 경고 후보가 되려면:

- 개발·검증표본에서 방향이 같음
- 검증표본 Holm 조정 p값 < 0.05
- 전체 이벤트 100건 이상 또는 희귀 신호 50건 이상
- 63일 중앙 시장초과수익률 차이가 `-3%p` 이하이거나 MAE가 대조군보다 `3%p` 이상 악화
- 다음 시가 매도 반사실이 10% 하위손실 또는 MDD를 20% 이상 줄임
- 그 대가로 포기한 63일 중앙수익이 2%p를 넘지 않음
- 상위 종목·연도 제거 후 방향 유지

통과하지 못한 신호는 앱에 넣지 않는다. 표본 부족은 실패가 아니라 `INCONCLUSIVE`로 분류한다.

## 9. 3차 배치 — 한국 RS 90 진입 품질

### 9.1 RS 정의

거래일 `D`의 적격 유니버스에서:

`rsRaw = 0.40 × R21 + 0.20 × R63 + 0.20 × R126 + 0.20 × R252`

- `R21`, `R63`, `R126`, `R252`는 `D`까지의 분할조정 가격 수익률
- `rsRank`는 같은 날 적격 유니버스 안의 횡단면 백분위
- 동률은 종목코드 오름차순으로 결정론적으로 처리
- Mansfield RS와 혼용 금지

### 9.2 진입 이벤트

- 전일 `rsRank < 90`, 당일 `rsRank >= 90`인 첫날
- 한 에피소드는 RS 90 아래에서 20거래일 연속 머물 때 종료
- 에피소드가 끝나기 전 재진입 이벤트 생성 금지

### 9.3 진입 시점에 알 수 있는 후보 특성

| 코드 | 가설 방향 |
|---|---|
| `Q1_RETURN_21D` | 21일 수익률 30% 미만 우수 |
| `Q2_MAX_DAILY_RETURN_63D` | 최근 63일 일간 +20% 이력 없음 우수 |
| `Q3_LIMIT_UP_COUNT_63D` | 최근 63일 상한가 0회 우수 |
| `Q4_DAYS_RS50_TO_RS90` | 50→90 소요기간이 길수록 우수 |
| `Q5_SIZE_PERCENTILE` | 시총 상위 1/3 우수 |
| `Q6_VOLUME_EXCESS_60D` | 거래량 과다가 낮을수록 우수 |
| `Q7_REALIZED_VOL_63D` | 변동성이 낮을수록 우수 |
| `Q8_UPPER_WICK_COUNT_60D` | 윗꼬리 횟수가 적을수록 우수 |
| `Q9_BOOM_BUST_COUNT_252D` | 붐버스트 반복이 적을수록 우수 |

`RS 90→97`은 이 목록에서 제외하고 보유 중 열화 트랙에 둔다.

세부 계산:

- Q1은 `close[D]/close[D-21]-1`이다.
- Q2는 최근 63일 일간수익률의 최댓값이다. +20% 이력 여부는 보조 이진값이다.
- Q3은 7.1절의 상한가 판정을 최근 63일에 적용한 횟수다.
- Q4의 RS 50 에피소드는 RS 50 아래 20거래일 연속 후 처음 50 이상이 된 날 시작한다. 그 시작일부터 RS 90 진입일까지 거래일 수를 센다. 504일 안에 에피소드 시작점을 확인할 수 없으면 `504+` 범주로 유지하고 버리지 않는다.
- Q5는 진입일에 유효한 직전 월말 시가총액 백분위다.
- Q6은 최근 60일 각 날짜의 `volume / 직전 20일 평균 volume` 중 최댓값이다.
- Q7은 최근 63일 일간수익률 표준편차에 `sqrt(252)`를 곱한 연환산 실현변동성이다.
- Q8은 최근 60일 중 `(high-close)/high >= 5%`인 날의 수다.
- Q9는 H5와 같은 비미래참조 상태기계로 최근 252일 안에 완료된 사이클 수를 센다.

### 9.4 2단계 확인 설계

#### 개발표본

- 9개 후보를 각각 연속형과 사전 정의된 임계값으로 평가
- 9개 주검정에 Holm 보정
- 방향이 2010~2014와 2015~2019에서 모두 같아야 함
- 개발표본 Holm p값 < 0.10이고 단조성이 확인된 특성만 생존

#### 검증표본

- 생존 특성의 방향을 유리하면 1, 불리하면 0으로 바꾼 동일가중 품질점수 생성
- 선택과 점수 생성 알고리즘 자체를 사전등록하므로 결과를 보고 가중치를 최적화하지 않음
- 품질점수 상위 1/3 대 하위 1/3의 126일 시장초과수익률 차이를 단 한 번 검정
- 검증표본 p값 < 0.05, 차이 2%p 이상, 방향 일치 시 통과

### 9.5 포트폴리오 확인

통과한 품질점수는 두 베이스에서 확인한다.

1. 모든 RS 90 신규 진입 코호트
2. 앱의 기존 신규 진입 후보 중 RS 90 이상 코호트

앱 적용 후보가 되려면:

- 검증표본 순 Sharpe +0.10 이상 또는 MDD 2%p 이상 개선
- CAGR 희생 1%p 이하
- 회전율·현금비중 급증이 결과를 설명하지 않음
- KOSPI/KOSDAQ 양쪽에서 방향 일치

RS 품질이 통과해도 앱 런타임의 전종목 백분위 계산은 별도 백엔드·배치 설계와 승인을 거친다.

## 10. 보조 트랙 — 런치패드/MA 수렴 돌파

### 10.1 주가설

앱이 이미 계산하는 MA20·MA60·MA150 수렴 상태에서 직전 20일 고점을 거래량 2배와 함께 돌파한 종목은 매칭 대조군보다 향후 126일 시장초과수익률이 높다.

### 10.2 주의

강의의 MA10·21·50·65·200 조합과 다른 **앱 변형 가설**이다. 강의 성과 수치와 직접 비교하지 않는다.

### 10.3 채택 기준

- 검증표본 126일 초과수익 차이 +2%p 이상
- 95% CI가 0 초과
- 이벤트 100건 이상
- 다음 시가 진입 포트폴리오가 순 Sharpe +0.10 이상 또는 MDD 2%p 이상 개선

통과하지 않으면 `maCompression`을 관찰용으로 남길지 제거할지 별도 코드 검토를 제안한다.

## 11. 독립 트랙 — 동적자산배분

- 상위 3개 중 음수 모멘텀 슬롯을 현금으로 두는 정확한 방식
- 원형 듀얼모멘텀과 변형 듀얼모멘텀의 위험·안전자산 목록

정의 후 다음 5개 전략을 같은 비용·기간으로 비교한다.

1. 정적 자산배분
2. 채권 DAA
3. 원형 듀얼모멘텀
4. 변형 듀얼모멘텀
5. 정적 50% + 변형 듀얼모멘텀 50%

주평가지표는 순 Sharpe, 가드레일은 MDD와 월 회전율이다. 특정 CAGR 또는 MDD 수치를 재현하는 것을 목표로 하지 않는다. 전략 채택은 백테스트와 별개로 자산배분 정책 변경 승인이 필요하다.

## 12. 미국 가설의 재개 조건

다음이 모두 확보되기 전에는 미국 개별주 가설을 검증하지 않는다.

- 날짜별 point-in-time 종목 유니버스
- 상장폐지 종목과 폐지가격
- 분할·배당 조정 일봉
- 당시 이용 가능했던 가격·시가총액·거래량
- 거래비용과 체결 제약
- 섹터 분류의 시점 일관성

SPY나 현재 생존 종목만으로 대리검증한 결과를 미국 개별주 RS 가설의 증거로 사용하지 않는다.

재개 시에는 한국 결과를 보고 미국 임계값을 조정하지 않고 다음 순서를 따른다.

1. 미국 데이터만으로 유니버스·상장폐지·기업행위·배당·시총·거래량 QA를 통과한다.
2. 5.6절과 동일한 팩터 이름과 계산 시점을 사용하되, 원화 금액 임계값은 미국 유니버스 내 분위로 대체한다.
3. 미국 강의 가설인 RS, 절대주가, 거래량 효과를 미국 내부에서 먼저 검정한다.
4. 한국과 미국의 효과 차이는 국가 더미와 `신호 × 국가` 상호작용으로 검정한다.
5. 양국의 데이터 기간이 다르면 겹치는 공통 기간과 각국 전체 기간을 분리 보고한다.
6. 한국과 미국의 거래비용·세금·가격제한폭 차이를 각 시장에 맞게 적용한다.

미국 데이터 확보 전에는 “한국 vs 미국 비교 결과”가 아니라 **“한국 결과, 미국 미검증”**으로 보고한다.

- 원천 `Amount`의 처리 JSON 재인제스트 및 매니페스트 QA
- G11용 data.go.kr 서비스키
- G8용 정상폐지 401건의 합병·자진상폐 대가 처리 방안
- 126일·252일 경제성 채택에 사용할 현금배당 포함 총수익 처리 방안

미국 비교를 실행하려면 추가로 필요:

- point-in-time 미국 종목 마스터와 상장폐지 포함 일봉
- 당시 시가총액·거래량·분할·현금배당 자료
- 미국 시장별 거래비용·세금·체결 제약
- 한국과 겹치는 공통 분석 기간

동적자산배분을 실행하려면 추가로 필요:

- 정확한 채권 ETF 8종
- 정적 자산군과 비중
- 현금 대체자산
- 리밸런싱·모멘텀 세부 정의

분할·병합 조정 파이프라인은 이미 구현·실행되어 있으므로 재구현하지 않는다. 새 하네스에서 기존 `adj_*` 사용과 미분류 종목 제외를 확인하고, 원천 `Amount` 재인제스트를 완료하면 2010~2022 개발·검증 실행이 가능하다. G8·G11이 없으면 2023~2025 잠금표본의 최종 채택을 선언할 수 없으며, 총수익 자료가 없으면 장기 경제성 결과는 조건부로만 해석한다. 미국 입력이 없으면 한국 연구는 진행할 수 있지만 국가 비교는 미검증으로 남는다.

## 18. 최종 성공 기준

이 연구의 성공은 많은 규칙을 발견하는 것이 아니다.

- 검증표본과 잠금표본을 모두 생존한 소수 규칙만 남긴다.
- 기존 규칙 대비 증분 가치가 없는 규칙은 제거한다.
- 통계적으로 유의하지만 경제성이 작은 규칙은 앱에 넣지 않는다.
- 경제성이 있어도 구현 불가능한 규칙은 연구 결과로만 남긴다.
- 데이터가 부족한 항목은 억지 프록시로 결론 내리지 않고 `INCONCLUSIVE`로 종료한다.
- 모든 주요 결과에 시장·시총·유동성·거래량·상승률·변동성·1일 충격 분해표가 있어야 한다.
- 한국 결과를 미국에 일반화하지 않고, 미국은 별도 데이터 게이트와 재현을 통과해야 한다.

최종 앱 후보는 **시장 위험 배지, 신규 진입 게이트, 보유 검토 경고** 세 종류로 제한한다. 자동매도와 자산배분 변경은 별도 정책 의사결정으로 남긴다.

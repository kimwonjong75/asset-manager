# 외부 강의록 검토 — 자체 백테스트 후보 선별 (2026-07-25)

출처: 외부 강의록 1건(드러켄밀러 포트폴리오 / AI 인프라 소프트웨어 / 동적자산배분 / RS 90 품질 필터 / 한국 급성 매도 시그널 / 저평가 논의).
목적: 강의에서 나온 주장 중 **우리 레포에서 자체 백테스트로 검증 후 앱 적용을 검토할 값어치가 있는 것**만 선별한다.

## 0. 판정 기준 (2축 분리)

혼동을 막기 위해 두 축을 반드시 분리한다.

| 축 | 질문 | 결정 요인 |
|---|---|---|
| **A. 자체 검증 가능성** | 우리 데이터·엔진으로 가설을 참·거짓 판정할 수 있는가 | 과거 데이터 보유 여부, 크로스섹션 하네스 유무 |
| **B. 앱 적용 가능성** | 검증에 성공했다면 런타임에 신호로 띄울 수 있는가 | 앱이 실시간에 그 지표를 계산할 수 있는가 |

**A와 B는 자주 어긋난다.** 대표적으로 RS(상대강도)는 백테스트로는 검증 가능하지만(로컬에 한국 전종목 일봉 보유), 앱 런타임은 보유·관심종목만 조회하므로 유니버스 백분위를 계산할 수 없다(`hooks/useEnrichedIndicators.ts:130-145`). 즉 **검증은 되는데 적용은 별도 공사**다.

### 전제: 강의 주장의 사전 신뢰도는 낮게 잡는다
강의에서 제시된 품질 필터 결과는 사전등록 없이 하룻밤에 산출된 다중 지표 스크리닝이다(지표 약 10종 × 시장 2 × 호라이즌 여러 개). 다중비교 보정 없이 나온 "동그라미 2개" 판정은 우연 발견을 대량 포함할 수밖에 없다. 따라서 우리 검증의 기본 기대는 **"대부분 기각, 소수 생존"**이며, 생존한 소수만 앱에 넣는다. RULES.md §13 및 `scripts/backtest/conditionalChannel/statistics.ts`의 `holmAdjust`(:203) 사용을 전제한다.

### P2 — 가치 높으나 인프라 신규 필요

#### C3. RS 90 진입 "품질" 필터 (한국) — 강의록의 최대 블록

| | |
|---|---|
| **가설** | RS 90 진입 종목 중, 진입 **전** 궤적이 완만했던 종목이 급등했던 종목보다 사후 6~12개월 성과가 유의하게 높다 |
| **검증 가능성** | ✅ **가능** — RS는 우리 데이터로 오프라인 계산 가능(전종목 유니버스 + PIT 월말 스냅샷 보유) |
| **앱 적용 가능성** | ❌ **현재 불가** — 앱은 유니버스 전체를 스캔하지 않음. RS 계산에 백엔드 또는 별도 배치 필요 |
| **비용** | 높음 — RS 계산기 + 일봉 패널 전방수익 어댑터 신규 |

검증 대상 서브가설 10종 (전부 진입 **전** 상태 기준):
1. 최근 1개월 상승률 <30% 가 우수
2. 최근 3개월 내 일간 +20% 이력 없음이 우수
3. 상한가 이력 0회가 우수 (③과 동일한 제도변경 주의)
4. RS 50→90 소요기간이 길수록 우수
5. 대형주 > 소형주 (시총 상위 1/3 ≈ 600종목 — `month_end` 스냅샷에 `large`/`percentile` 사전계산됨)
6. 최근 60일 거래량 과다가 열등
7. RS 90→97 급등이 열등
8. 최근 3개월 변동성 낮음이 우수
9. 최근 60일 윗꼬리(고가 대비 종가 −5%↑) 5회 초과가 열등
10. 붐버스트(1년 내 +50% 후 −30%) 2회 이상이 열등

**RS 정의를 먼저 동결할 것**: 강의는 종합 RS(1M 40% / 3M 20% / 6M 20% / 12M 20%)를 쓴다 — 이 산식은 이미 `constants/knowledgeBase.legacy.ts:115`에 문자열로 기록돼 있으나 계산 코드가 없다. 또한 `types/knowledge.ts:104-105`에 **"rsRank(유니버스 백분위)와 Mansfield RS(지수 대비)를 혼동 금지"** 설계 결정이 박혀 있으므로 이를 따른다.

**권고**: C3은 **검증만 먼저** 수행하고, 앱 적용은 결과가 강하게 생존했을 때 별건 승인으로 다룬다. 검증 자체의 가치는 크다 — 통과하면 draft로 죽어 있는 RS 규칙 2개(`rule-rs-90-screening`, `rule-ma-pullback-entry`)의 운명을 근거 있게 결정할 수 있다.

**C3-b (파생, 저비용)**: 위 지표 중 **진입 전이 아니라 보유 중 열화 감지**로 쓰는 변형 — 변동성 급증·윗꼬리 누적·붐버스트 반복을 보유 종목 경고로. 이건 RS가 필요 없어 **앱 적용 가능**하고, C1과 같은 하네스로 검증된다. C1 다음으로 가성비가 좋다.

### P3 — 인프라는 있으나 사용자 실행성이 쟁점

#### C5. 동적자산배분 (정적 50 : 동적 50), 변형 듀얼모멘텀 안전자산

| | |
|---|---|
| **가설** | (a) 정적·동적 배분의 상관이 낮아 병행 시 MDD가 10% 미만으로 내려간다 (b) 듀얼모멘텀 안전자산을 AGG 단독에서 채권 DAA(8종 중 상위 3 또는 현금)로 바꾸면 성과·MDD가 개선된다 |
| **검증 가능성** | ✅ **엔진 이미 완성** — `sectorRotation/lib/strategy.ts`(절대+상대 모멘텀, 현금 대피 `cashSymbol: BIL`, 월 리밸런싱, 버퍼 교체), `lib/coreBasket.ts`(정적배분+리밸런싱), `bondRole/run.ts`(채권 다리 역할 비교, 실행 완료) |
| **앱 적용 가능성** | ⚠️ 조건부 — 앱은 정적 90/10 + 터틀 구조. 동적 배분은 새 축이며 **매월 실행이 필요** |

**핵심 쟁점은 검증이 아니라 실행성**이다. 강의자 본인도 "귀찮아서 안 한다"고 밝혔고, 우리 사용자의 진단된 문제도 정확히 "실행"이다(메모리: 94종목/60손실, 실행이 문제). 그런데 **바로 그 지점이 앱의 강점**이기도 하다 — 이미 `useActionQueue`/`useTurtleActionReview`로 월별 실행 큐를 만들 수 있는 구조가 있다.

**단서**: `bondRole` 결과(미커밋)는 3년 구간에서 채권 **제외**가 CAGR 27.0% / MDD −11.4%로 포함(21.4% / −10.1%)보다 우수했다 — 즉 "안전자산이 안전하지 않았다"는 강의의 문제 제기와 같은 방향의 관찰이 우리 데이터에도 이미 있다. C5는 이 관찰의 후속으로 자연스럽다. 다만 3년은 표본이 짧다(레짐 1개).

**전제 조건**: 동적 배분 도입은 자산 배분 정책 변경이므로 **사전 승인 필요**(CLAUDE.md). 검증까지만 자율 진행.

## 4. 공통 방법론 규율 (착수 전 필수)

레포의 기존 관례(RULES.md §13, `PHASE1/2_PREREGISTRATION.md`, `PREREG_조건부채널-KR-Size.md`)를 그대로 따른다.

1. **사전등록 우선** — 결과를 보기 전 `docs/backtest/PREREG_*.md` + `preregistered-config*.json` + SHA-256 설정해시 동결. 필수 필드: `primaryEstimand`, `hypothesisDirection`, `sampleSplit`(개발/검증/**잠금** 3분할), `statistics`(부트스트랩 반복·시드·HOLM), `masterSeed`
2. **다중비교 보정 필수** — C1은 6가설, C3은 10가설 × 호라이즌 3종 = 최대 30검정. `holmAdjust`(`statistics.ts:203`) 적용 없이는 "발견"이라 부르지 않는다
3. **룩어헤드 프리** — PIT 월말 유니버스 스냅샷 사용, 진입 시 그룹 동결. 기존 교훈: 분포일 50일 평균은 당일 i를 **제외**해야 했다
4. **잠금표본 봉인 유지** — G8/G11 미통과 상태에서 2023–2025를 만지지 않는다. 개발은 2010–2022
5. **골든값 parity 테스트** — 절대 골든값을 손계산으로 못 박는다(path-A vs path-B 비교는 자기참조 동어반복). `tests/<name>Parity.ts` 신규 + `npm run build`
6. **결정론** — `Math.random` 금지, `mulberry32` 시드 고정
7. **결과가 나빠도 그대로 보고** — 튜닝 재탐색 금지(`phase2.ts:3-4` 관례). 참고: 기존 `conditionalChannel` 4전략이 전부 CAGR −36%대로 참패했고 그대로 기록돼 있다
8. **우선주 필터 재확인** — 현재 분류가 "종목코드 끝자리 0 또는 5" 휴리스틱이어서 우선주 1,924개로 과대 집계되고 investable이 43%(1,258/2,903)에 불과하다. 새 리서치는 이 필터를 반드시 재검토할 것
9. **거래대금 프록시 명시** — `close × volume`은 진짜 거래대금이 아니다. C1-⑤, C3-6 결과 보고 시 반드시 표기

| 4 | **C3-b** 보유 품질 열화 경고 | 지표 4종(변동성/윗꼬리 카운트/붐버스트) | 낮음~중간 |

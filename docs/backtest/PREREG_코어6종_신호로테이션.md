## 1. 연구 질문과 기존 연구와의 분리

고정 비중 코어 6종에 매도·재진입 신호를 적용하고, 매도 자금을 현금 또는 다른 활성 코어 자산으로 옮겼을 때 다음을 검증한다.

1. 달력 리밸런싱 없는 B&H보다 최대낙폭(MDD)을 줄이는가?
2. 그 대가로 CAGR이 B&H보다 연 2%포인트 넘게 낮아지지 않는가?
3. Calmar, 비용 2배, 시작일 변경, 검증 구간, leave-one-out, 자산별 상한 민감도에서도 방향이 유지되는가?
4. 1단계에서 고른 규칙 2개에 분할 재진입을 붙이면 재진입 직후 위험과 전체 MDD가 추가로 줄어드는가?

이 연구는 아래 기존 연구를 설계 재사용의 근거로만 삼고, 결과는 섞지 않는다.

- `holdings-turtle-cycle-v1`: 종목별 독립 자본곡선의 보유→현금→재진입 연구
- `portfolio-turtle-v1`: 다종목 공유 현금, 다음 실제 거래일 시가 체결, 동시주문 비례축소, 비용·현금이자·LOO·회계 불변식 연구
- 기존 보고서의 수치나 추천을 이번 연구의 사전확률, 점수 또는 통과 근거로 사용하지 않는다.
- 새 보고서에는 기존 연구 결과와 새 코어 6종 결과를 별도 절로 유지한다.

### 4.4 프록시 통과 게이트

계층 A 겹침 구간에서 전략 손익을 보기 전에 다음 데이터 충실도만 계산한다.

- 일별 원화 총수익 상관계수 ≥ 0.90
- OLS beta 0.80~1.20
- 연율화 추적오차 ≤ 10%
- 일간 수익률 방향 일치율 ≥ 70%
- 각 규칙의 상태(보유/매도) 일치율 ≥ 75%
- 신호일 ±2 KRX 거래일 안의 이벤트 일치율 ≥ 70%

주 프록시는 이 문서에서 `SPY`, `3188.HK`, `385560`, `TLT`, KRX 금현물로 동결한다. 검증기간을 포함한 겹침 구간의 상태·이벤트 일치율은 **충실도 진단에만** 쓰며 프록시 선택·재선택에 쓰지 않는다. 한 자산이라도 게이트에 실패하면 전략 결과를 열지 않고 어떤 게이트가 실패했는지만 보고한다. `IVV`, `ASHR` 같은 대체 후보를 사후 선택하지 않으며, 대체안은 별도 연구 ID와 사용자 재승인을 받아야 한다. 385560에는 대체 후보가 없다. 이 규칙은 검증구간 정보를 입력 시계열 선택에 쓰는 간접 선택 누수를 막기 위한 것이다.

상태·이벤트 게이트는 모두 동일하게 `active`로 초기화하고 55개 완료봉 워밍업 뒤부터 잰다. 비교 양쪽 모두 이벤트가 0건이면 이벤트 일치율은 100%, 한쪽만 0건이면 0%로 정의하고 발생 건수도 함께 공개한다.

## 5. 총수익·환율·캘린더·시차

### 5.1 총수익 처리

- 모든 자산은 분배금 재투자 세전 총수익을 우선한다.
- 원시 OHLC와 분배·분할 조정계수를 확보하면 각 날짜의 O/H/L/C에 동일한 시점 조정계수를 곱해 총수익 조정 OHLC를 만든다. 고가·저가만 별도 방식으로 조정하지 않는다.
- 조정계수 출처와 산식, 분배락일, 분할 이벤트를 데이터 매니페스트에 저장한다.
- 조정 OHLC를 만들 수 없는 데이터는 주 연구에서 제외한다. 단순 시장 종가를 총수익으로 가장하지 않는다.
- ETF 보수는 NAV/시장가격에 이미 반영된 것으로 보고 별도 차감하지 않는다. 매매비용·슬리피지는 별도 반영한다.

### 5.2 환율

- 379800 프록시: SPY의 USD 가격에 시점 일치 USD/KRW를 곱한다.
- 283580 프록시: 3188.HK의 HKD 거래가격에 HKD/KRW를 곱한다. HKD/KRW는 직접 고시 우선, 없으면 USD/HKD와 USD/KRW의 같은 시점 교차환율을 사용한다.
- 464470 프록시: TLT의 USD 가격에 USD/KRW를 곱한다.
- 환헤지 비용을 차감하지 않는다. 세 상품 모두 환노출이기 때문이다.
- 미래의 서울 종가 환율을 앞선 해외시장 체결에 소급하지 않는다. 각 신호·체결 시각 이전에 관측 가능한 마지막 환율만 사용한다.
- 외화자산의 원화 시가와 종가는 각각 원천시장 시가·종가 시각까지 공개된 마지막 환율로 환산한다. 체결도 같은 시점의 가용 환율을 사용한다.
- 일봉만으로는 자산 고가와 환율 고가가 동시에 발생했다고 알 수 없으므로 원화 고가·저가를 정확한 체결가능 가격이라고 부르지 않는다. 주 근사는 `KRW high = 현지통화 high × 같은 세션 FX high`, `KRW low = 현지통화 low × 같은 세션 FX low`인 보수적 비동시각 외곽값으로 고정한다. 신호 확정 뒤에만 사용하고 체결가에는 쓰지 않는다.
- 왜곡 민감도는 현지통화 H/L에 각각 신호시점 직전 가용 FX를 곱한 고정환율 H/L로 다시 계산한다. 두 방식에서 규칙 선택이나 주 결론이 뒤집히면 `환율 일봉 근사에 불안정`으로 표시한다. 장기 동시시각 자산·FX 자료를 확보하면 그 자료가 두 일봉 근사보다 우선하되, 데이터 매니페스트 공개와 사용자 확인 전에는 교체하지 않는다.

### 5.3 거래일과 시차

- 각 원천 거래소의 실제 거래일·현지 개장/마감 시각을 UTC 타임스탬프로 정규화한다.
- D일 확정 종가 신호는 그 종가가 실제로 확정된 시각 이후에만 생성된다.
- 주문은 **그 자산 원천시장의 다음 실제 거래일 시가**에 체결한다. 휴장일에는 체결하지 않는다.
- 미국 종가를 같은 날짜의 이미 끝난 한국 시가에 체결시키지 않는다. 중국 종가도 같은 날 09:00 KRX 시가로 소급하지 않는다.
- 계층 A 실제 ETF는 전부 KRX이므로 D일 15:30 종가 신호 → 다음 KRX 거래일 09:00 시가다.
- 계층 B는 KRX·미국·홍콩 이벤트가 UTC 순서대로 발생한다. 일별 포트폴리오 평가는 모든 주 시장이 닫힌 뒤인 매일 22:00 UTC에, 그 시점까지 관측된 가장 최근 가격과 환율로 한다. 이미 관측된 당일 시가를 이전 종가로 되돌려 평가하지 않는다.
- 현금이자는 직전 평가시점부터의 실제 경과 달력일에만 발생시키며, 금리는 각 시점까지 공개된 마지막 값을 사용한다.
- 환율·휴장·시차 정렬표와 각 주문의 `signalTimestamp < fillTimestamp`를 결과 감사파일에 남긴다.

- 개발 구간: 2021-08-16~2023-12-29.
- 검증 구간: 2024-01-02~2026-09-30.

첫 유효일이 늦어지면 개발 구간 시작만 뒤로 이동한다. 검증 경계와 종료일은 바꾸지 않는다. 개발 구간이 2년 미만 또는 검증 구간이 2년 미만이 되면 연구 전체를 `INCONCLUSIVE`로 표시하고 실행 전 사용자에게 다시 보고한다.

시작일 민감도는 각 구간의 첫 공동 평가일을 기준으로 0·21·42·63·84·105·126·147·168·189·210·231 거래일 뒤의 12개 후보를 사용한다. 각 시작점은 동일 종료일까지 평가하며, 최소 504개 공동 평가일이 남지 않으면 제외한다. 제외 후 **유효 시작점 `n`이 최소 6개**여야 하며 미달이면 해당 구간을 `INCONCLUSIVE`로 처리한다. 모든 규칙은 같은 유효 시작점 집합을 사용한다. 추가로 완성된 504개 공동 평가일 롤링창을 63개 공동 평가일 간격으로 계산한다.

## 7. 비교 전략

### A. B&H

- 시작 시각에 목표비중별 원화 예산을 고정하고 각 원천시장의 첫 실제 시가에 순차 매수한다. 아직 열리지 않은 시장의 예산은 현금으로 남긴다. 모든 비교군이 같은 초기 주문·환율·비용을 사용한다.
- 이후 달력 리밸런싱과 신호 이동이 없다.
- 분배금 재투자를 포함한 총수익만 반영한다.

### B. 매도 후 현금 유지

- 신호가 꺼진 자산을 전량 매도하고 해당 자산의 재진입 신호 전까지 현금으로 둔다.
- 주 시나리오 현금수익: 한국은행 ECOS의 일별 CD 91일 금리에서 연 0.25%p를 차감하고 0%를 하한으로 한 뒤 ACT/365 일복리한다. [한국은행 ECOS](https://ecos.bok.or.kr/)는 CD(91일)를 일일지표로 제공한다.
- 민감도: 현금수익 0%.

### C. 신호 기반 자산 로테이션

- 매도된 자금은 체결 시점에 `active`인 다른 코어 자산에 원 목표비중 비례로 배분한다.
- 기본 상한: `min(원 목표비중 × 1.5, 35%)`.
- 6종 상한은 각각 25.5%, 25.5%, 24.0%, 18.75%, 18.75%, 35.0%다.
- 상한 초과분과 모든 자산이 매도 상태인 경우만 현금으로 둔다.
- 재진입 자산은 다른 활성 자산을 목표비중 비례로 축소해 허용 목표까지 복귀한다.
- 신호 변화 또는 추가매수 체결일에만 재배분한다. 가격 변화만으로는 리밸런싱하지 않는다.
- 상한 1.25배와 2.0배는 민감도이며 본 판정에 쓰지 않는다.

### 7.1 동시주문과 비례축소

동일 UTC 타임스탬프에 여러 주문이 있으면 다음 순서를 고정한다.

1. 취소 대상 미체결 주문 제거
2. 매도 주문 전부 체결(티커 순서는 손익에 영향 없어야 함)
3. 비용 차감 후 현금과 순매도대금 확정
4. 재진입 주문
5. 불타기 추가매수 주문
6. 필요한 총매수금액이 현금보다 크면 모든 매수 희망금액에 공통 계수 `λ∈[0,1]`를 곱해 비례축소
7. 각 자산 상한과 최소 주문금액을 다시 검사하고, 절사 후 남은 현금은 보유

종목 선착순 배분은 금지한다. 프록시 연구는 소수점 수량을 허용한 연속수량 결과를 주 결과로 하고 정수 주 결과를 실행 민감도로 별도 표시한다. 초기자본은 1억원, 연속수량 주 결과의 최소 주문금액은 1만원으로 고정한다. `λ`는 비용까지 포함한 총 필요현금이 가용현금 이하가 되는 최대 공통계수로 수치해석하며 허용오차는 1원이다. 모든 최종 동률의 안정적 정렬키는 이 표의 종목코드 오름차순으로 하되, 공통 `λ` 때문에 입력 순서가 경제적 배분을 바꾸면 실패다.

서로 다른 시장의 재원을 같은 시각에 존재한다고 가정하지 않는다.

- 원래 신호 주문은 해당 자산의 다음 실제 시가에 체결한다.
- 재진입·추가매수에 다른 시장 자산의 축소가 필요하면 축소 매도를 각 원천시장의 다음 실제 시가에 먼저 체결한다. 비용 차감 뒤 실제로 생긴 현금만 재원으로 인정하고, 그 뒤 대상 자산의 첫 실제 시가에 매수한다.
- 이미 보유한 현금만으로 가능한 부분은 먼저 비례 체결할 수 있다. 미래 매도대금 선사용, 음수 현금, 암묵적 차입은 금지한다.
- 매도 체결 뒤 결제일까지의 법적 출금 제한은 주 연구에서 모형화하지 않고 체결 즉시 포트폴리오 내부 재사용 가능하다고 가정한다. 대신 `T+2` 재사용 민감도를 별도 표시하며 결론이 바뀌면 결제 가정에 불안정하다고 판정한다.
- 자금조달 묶음이 완료되기 전에 다른 신호가 active 집합이나 상한을 바꾸면 남은 미체결 주문을 취소하고, 그 시점까지 실제 체결된 현금·보유량만으로 새 묶음을 계산한다. 구간 종료 뒤 체결될 주문은 취소한다.
- 상한은 매수 직후 평가액에 적용한다. 가격·환율 변화만으로 생긴 수동적 상한 초과는 기록하되 강제매도하지 않는다. 이미 초과한 자산에는 추가매수하지 않으며 초과폭을 확대하는 매수는 금지한다.

## 8. 1단계 신호 규칙

공통 원칙:

- 도치안 채널은 D일 현재 봉을 제외한다. MA와 Wilder 방식 ATR20은 D일 완료 OHLC까지 포함한다.
- `N`은 신호가 확정된 D일의 Wilder ATR20이다.
- 도치안은 상태 조건이다. 보유 중 `close_D <= priorLow`면 1회 매도 예약, 현금 중 `close_D >= priorHigh`면 1회 재진입 예약한다.
- MA는 교차 조건이다. 매도는 `close_D <= MA_D`이고 직전 유효일 `close > MA`; 재진입은 `close_D >= MA_D`이고 직전 유효일 `close < MA`일 때만 발생한다.
- ATR 트레일은 실제 진입 이후 관측한 일중 고가의 최고값에서 `3×ATR20_D`를 뺀 값이며 하향하지 않는다. `close_D <= trail_D`면 매도한다.
- 미체결 주문이 있거나 같은 상태 주문이 이미 예약된 동안 동일 신호를 반복 생성하지 않는다.
- 같은 D일에 매도와 추가매수 조건이 함께 참이면 매도가 우선한다.

| ID | 매도 | 재진입 |
|---|---|---|
| D10/20 | 직전 10개 완료봉 최저가 이하 종가 | 직전 20개 완료봉 최고가 이상 종가 |
| D20/55 | 직전 20개 완료봉 최저가 이하 종가 | 직전 55개 완료봉 최고가 이상 종가 |
| D55/55 | 직전 55개 완료봉 최저가 이하 종가 | 직전 55개 완료봉 최고가 이상 종가 |
| MA20 | MA20 하향 교차 | MA20 상향 교차 |

### 8.1 개발 구간 상위 2개 선택

선택 대상은 전략 C, 기본 상한 1.5배, 기본 비용, 주 현금금리, 불타기 없음이다.

1. 개발 구간 유효 시작점 `n` 중 `ceil(n/2)`개 이상에서 CAGR이 해당 B&H보다 2%p 넘게 낮지 않은 규칙만 적격이다.
2. 적격 규칙을 시작점별 `B&H 대비 MDD 상대 축소율` 중앙값 내림차순으로 정렬한다.
3. 동률은 Calmar 개선 중앙값, 비용 2배 MDD 방향 유지 비율, 낮은 회전율 순으로 푼다.
4. 상위 2개를 고정하고 그 뒤 개발 구간의 2단계 선택만 연다. 1·2단계 선택을 모두 고정한 뒤에만 검증 구간을 연다.
5. 적격 규칙이 2개 미만이면 2단계를 강행하지 않고 `INCONCLUSIVE` 또는 “코어에 터틀을 적용하지 않음”으로 보고한다.

검증 구간은 선택에 절대 사용하지 않는다.

## 9. 2단계 분할 재진입·불타기

1단계에서 고른 두 규칙에만 적용한다. `허용 목표비중`은 해당 체결 시점의 전략 C 배분과 자산 상한으로 계산한다.

| 방식 | 최초 재진입 | 추가 조건 | 추가 크기 |
|---|---:|---|---:|
| 없음 | 허용 목표 100% | 없음 | 없음 |
| 터틀식 | 허용 목표의 1/4 | 마지막 실제 체결가 + 0.5N | 최초 유닛과 같은 1/4, 최대 3회 |
| 2R | 허용 목표의 1/4 | 마지막 실제 체결가 + 2R. 여기서 `1R=2N`, 따라서 간격은 4N | 최초 유닛과 같은 1/4, 최대 3회 |
| 앱형 | 허용 목표의 8/15 | 마지막 실제 체결가 대비 +10% | **직전 유닛의 절반**: 4/15, 2/15, 1/15, 최대 3회 |

유닛 크기는 **주식 수가 아니라 최초 재진입 체결 직전에 확정한 원화 허용 목표금액**의 비율이다. 앱형의 `절반`은 최초 유닛의 절반을 매번 반복하는 뜻이 아니라 직전 계획 유닛 금액의 절반이다. 8/15+4/15+2/15+1/15=최초 허용 목표금액 100%가 되도록 정규화한다. 이는 현재 앱 로직과 동일하다고 주장하지 않는 연구 전용 정의다.

- N과 R은 최초 재진입 신호일 값으로 해당 재진입 캠페인 동안 고정한다.
- 캠페인의 허용 목표금액과 계획 유닛 금액도 최초 재진입 주문 생성 때 고정한다. 현금·상한·최소주문 때문에 줄어든 미체결분은 나중에 보충하지 않는다. 따라서 가격 변화 뒤 평가액이 최초 목표금액과 정확히 같아질 것을 요구하지 않는다.
- 추가매수는 D일 종가가 문턱 이상일 때 예약하고 다음 실제 거래일 시가에 체결한다.
- 하루에 한 단계만 추가한다. 갭으로 여러 문턱을 넘겨도 연쇄 체결하지 않는다.
- 추가매수 재원은 현금과 다른 활성 자산의 목표비중 비례 축소로 마련한다.
- 모든 매수 후 동일 자산 상한을 다시 적용한다.
- 평균단가는 실제 체결금액과 비용을 포함한 수량가중평균으로 기록하지만 신호선 계산에는 사용하지 않는다.
- 별도의 매수가 기반 2N 손절을 새로 추가하지 않는다. 청산선은 선택된 1단계 규칙 그대로이며 ATR 트레일은 기존처럼 하향 금지다. `R=2N`은 2R 방식의 간격 단위일 뿐 추가 손절 규칙이 아니다.
- 매도 신호가 발생하면 남은 유닛 전부를 하나의 주문으로 청산하고 미체결 추가매수를 취소한다.
- 모든 비교군은 시작 시점에 여섯 자산을 목표비중으로 동일하게 편입하며 신호전략의 초기상태는 `active`다. 워밍업 신호를 시작 시점의 가상 포지션 상태로 소급하지 않는다.
- 상태는 `active`, `exit_pending`, `inactive`, `funding_pending`, `reentry_pending`, `pyramiding`으로 구분한다. 다른 자산의 로테이션이 미완성 분할재진입 캠페인을 자동으로 채우지 않는다.

재진입 후 21·63 거래일 구간의 MDD, 손실확률, 현금투입률을 별도 집계해 “초기 위험 축소”를 평가한다.

## 10. 비용·세금·체결

- 주 결과는 세전 총수익이다.
- 기본 편도 비용: 체결금액의 0.10%(수수료+슬리피지 연구 가정).
- 비용 2배: 편도 0.20%.
- 실제 다음 시가를 사용하며 신호가격·채널·손절선으로 체결가를 클램프하지 않는다.
- 한국 상장 ETF의 거래세는 0으로 둔다. 계좌별 배당소득세·보유기간과세·연금계좌 과세는 주 결과에서 제외한다.
- 세후는 계좌 유형을 명확히 분리할 수 있을 때만 민감도 부록으로 계산한다. 계좌정보가 없으면 계산하지 않는다.

## 11. 지표와 판정

주 판정은 검증 구간의 전략 C가 같은 시작점 B&H와 비교해 모두 충족해야 한다.

- `MDD 상대 축소율 = (|MDD_BH| - |MDD_strategy|) / |MDD_BH|` ≥ 20%. B&H MDD=0이면 비율은 `N/A`이고 이 기준은 미충족이다.
- `CAGR 절대차 = CAGR_strategy - CAGR_BH` ≥ -2%p
- `CAGR 감소비율 = (CAGR_BH - CAGR_strategy) / |CAGR_BH|`도 함께 표시. B&H CAGR=0이면 `N/A`.
- Calmar가 B&H보다 높음. CAGR≤0이고 MDD<0이면 Calmar=CAGR/|MDD|, MDD=0이면 양의 CAGR은 `+∞`, 0 CAGR은 0, 음의 CAGR은 `-∞`로 정한다.
- 기본 비용과 비용 2배에서 MDD·Calmar 개선 방향 유지
- 유효 시작점 `n`의 과반(`floor(n/2)+1`)에서 MDD 축소와 CAGR 하한을 동시에 충족
- 6개 leave-one-out 중 최소 5개에서 `MDD가 B&H보다 작고 CAGR 절대차가 -2%p 이상`인 방향 유지
- 상한 1.25배·2배 중 하나라도 주 결론이 반대로 바뀌면 `불안정`

보조 보고 항목:

- CAGR, MDD, Calmar, 최종가치, 회복기간
- 거래횟수, 연 환산 회전율, 평균·최대 현금비중
- 휩쏘: 매도 후 20거래일 안에 더 높은 총수익 조정가격으로 재진입
- 자산별 손익·MDD 기여, 최대 기여 집중도
- 연도·분기별 초과성과와 최악 낙폭 에피소드
- 특정 자산을 뺀 6개 LOO

자산 집중도는 각 자산을 하나씩 제거해 얻은 전략−B&H 최종가치 차이의 변화를 기여도로 정의하고, 최대 절대기여/절대기여 합을 표시한다. 시간 집중도는 단일 연도의 전략−B&H 초과손익이 전체 양의 초과손익에서 차지하는 비중을 표시한다.

- LOO에서는 제거 자산을 뺀 원 목표비중을 합계 100%로 재정규화하고, 그 재정규화 비중에 `min(배수×목표비중, 35%)` 상한을 다시 계산한다.
- 절대기여 합 또는 전체 양의 초과손익이 0이면 집중도는 `N/A`다. 최대 자산 절대기여 비중이 50% 초과하거나 단일 연도 비중이 60% 초과면 `집중 위험`으로 표시하고 강건한 채택 결론을 내리지 않는다.
- 2단계 네 방식은 개발 구간에서 모두 비교한다. 각 1단계 규칙마다 §8.1과 같은 적격·정렬법으로 한 방식을 고정한 뒤에만 검증을 연다. 검증에서 가장 좋아 보인 방식을 새 우승자로 바꾸지 않으며 나머지 조합은 탐색 결과로만 표시한다.

## 13. 결과 공개 순서와 수정 정책

1. 원천·라이선스·결측·첫/마지막 날짜·조정계수 데이터 매니페스트 작성

3. 게이트 통과 후 엔진 골든·불변식 테스트
4. 개발 구간만 실행해 1단계 상위 2개와 각 규칙의 2단계 방식 1개를 고정

구현 결함은 전략 결과를 보지 않은 상태에서 수정한다. 결과를 본 뒤 발견한 결함은 결과를 봉인하고 결함·영향·수정안을 먼저 사용자에게 보고한다. 전략 조건·판정 기준 변경은 새 연구 ID와 새 승인 없이는 금지한다.

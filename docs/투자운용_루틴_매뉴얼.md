# Asset Manager 실전 투자 플레이북

> 오늘 화면, 매매 계획(손절선·익절선·추세선·불타기선), 카카오톡 알림, 구루 신호 엔진, 참고 지표, 신호 리플레이, 대표 매수 종목을 하나의 투자 루틴으로 연결하는 따라 하기 매뉴얼.
>
> 앱 기준일: 2026-09-04(오늘 화면·매매 계획·카카오톡 알림 반영 갱신)

이 플레이북의 목표는 더 많은 신호를 찾는 것이 아니다. **관찰할 때, 연구할 때, 계획할 때, 실제로 기록할 때를 분리하여 충동적인 결정을 줄이는 것**이다.

> **한 문장 원칙: 구루 신호와 참고 지표는 관찰, 리플레이는 연구, 매매 계획은 사기 전에 미리 정하는 약속, 실제 매매는 오늘 화면에서 기록한다.**

이 문서는 앱 사용법과 운용 규율을 설명한다. 수익을 보장하거나 특정 종목의 매수·매도를 권유하지 않으며, 실제 투자 결정과 체결의 책임은 사용자에게 있다.

## 0. 30초 만에 이해하는 전체 지도

### 기능별 권한

| 기능 | 권한 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| **구루 신호 엔진** | 🟡 관찰 | 현재 보유·관심 종목 중 조건에 맞는 후보를 찾는다 | 직접 주문을 만들지 않는다 |
| **참고 지표** | 🟡 경고 | 과열 리스크를 한 번 더 확인한다 | 고점이나 폭락 시점을 예측하지 않는다 |
| **신호 리플레이**(더보기 → 연구실) | 🔵 연구 | 현재 규칙을 과거 가격에 적용하여 타이밍을 복기한다 | 라이브 규칙이나 실제 주문을 바꾸지 않는다 |
| **③ 대표 매수 종목** | ⚙️ 설정 | 코어 카테고리가 부족할 때 살 종목을 예약한다 | 지정만으로 주문을 만들지 않는다 |
| **매매 계획** | 🟢 계획 | 사기 전에 손절선·익절선·추세선(·불타기선)을 미리 정해 저장한다 | 계획을 세운다고 자동으로 매도·매수하지 않는다 |
| **오늘 화면** | 🔴 실행 | 계획 신호(긴급/오늘 실행/준비)와 대기 주문(리밸런싱·대청소)을 등급별로 모아 처리한다 | 새로운 투자 아이디어를 연구하지 않는다 |
| **카카오톡 알림**(선택) | 🟡 확인 채널 | 손절선·익절선 도달과 추세선 이탈을 앱 밖에서 알려준다 | 대신 팔아주지 않는다 — 손절은 증권사 예약주문이 먼저다 |
| **오늘의 터틀 확인** | 🟡 관찰(잠금) | 위성 55일 돌파·손절선·청산선 도달 여부만 보여준다 | 터틀 주문은 관찰 전용 잠금 상태라 이 화면에서 실행되지 않는다 |

### 앱을 쓰는 선순환

```text
관찰                 연구                   계획                    실행                    복기
대시보드        →     신호 리플레이     →    매매 계획 세우기   →    오늘 화면          →     주간 기록
구루/참고 지표        더보기 → 연구실         손절선·익절선 정하기      긴급→오늘실행→준비 순      반복 실수 확인
```

이 흐름을 거꾸로 사용하지 않는다. 예를 들어 참고 지표에서 과열 경고가 보였다는 이유만으로 바로 매도하거나, 리플레이에서 좋아 보인 숫자를 곧바로 라이브 규칙으로 믿지 않는다. 코어 자산(장기 자산배분)은 이 선순환과 별도로 **③ 대표 매수 종목 + 반기 리밸런싱**으로 관리한다(§5).

### 권장 시간표

| 주기 | 시간 | 미션 |
|---|---:|---|
| 매일 | 8분 | 오늘 화면 확인·처리 5분 + 대시보드 관찰 3분(카카오톡 알림을 켜 두면 대부분 시간에는 열어보기만 하면 된다) |

| 반기 | 60분 | 코어 목표 점검과 리밸런싱 주문 생성 |

## 1. 첫날 미션 — 시스템을 출발선에 세우기

처음 한 번만 제대로 설정하면 이후에는 정해진 루틴만 반복하면 된다. 상세 화면 설명은 [앱 운용 설정 따라하기 매뉴얼](운용설정_따라하기_매뉴얼.md)을 참고한다.

### 미션 1 — 돈의 역할을 나눈다

리밸런싱 화면의 `포트폴리오 리밸런싱 (2단 배분표)`에서 다음 항목을 확인한다.

- `목표 총 자산 (KRW)` 입력
- `① 전략 배분 — 코어 vs 투더문` 비중 설정
- `② 코어 자산배분 — 카테고리별` 목표 비중 설정
- 모든 비중의 합계 확인
- `저장하기`를 누르고 `저장됨!` 확인

**코어**는 자산배분과 반기 리밸런싱으로 관리한다. **투더문(위성)**은 터틀 후보 지정과 **매매 계획**(손절선·익절선·추세선)으로 관리한다. 같은 종목을 두 전략의 지시에 따라 동시에 움직이지 않는 것이 핵심이다.

계정 축을 쓰는 경우 한 가지 더: **유선 계정 자산은 코어·위성 어느 전략에도 넣지 않는다.** 유선은 상시 전략 제외이고 매도 경보만 유지된다. 통합 뷰에서 비중을 볼 때 이 부분을 혼동하지 않는다.

### 미션 2 — 코어의 장보기 목록을 만든다

`③ 대표 매수 종목 지정 (코어 리밸런싱 매수용)`에서 각 코어 카테고리가 부족할 때 살 종목을 지정한다.

좋은 대표 종목의 실무 조건은 다음과 같다.

- 해당 코어 카테고리의 목적을 대표한다.
- 실제 사용하는 증권사에서 거래할 수 있다.
- 티커와 거래소가 정확하다.
- 장기간 유지할 수 있어 반기마다 바꿀 필요가 없다.
- 같은 카테고리 안에서 무엇을 살지 미리 결정하여 당일 감정을 끼워 넣지 않는다.

지정 또는 변경 후 반드시 상단의 `저장하기`를 누른다. 미저장 변경이 있으면 리밸런싱 주문 생성 버튼이 비활성화된다.

> 대표 매수 종목은 “좋아 보이는 종목 추천”이 아니다. **해당 카테고리가 목표보다 부족할 때 사용할 기본 도구**다.

### 미션 3 — 위성의 운동장을 정한다

**설정 탭 → "터틀(위성) 실행"** 섹션 상단의 `터틀(위성) 예산`을 설정하고, 관심종목에서 터틀 전략을 적용할 위성 후보에만 🐢 표시를 붙인다.

- 코어 자산에는 터틀 후보를 켜지 않는다.
- **터틀 주문(신규 진입·불타기·손절·청산)은 현재 관찰 전용으로 잠겨 있다** — 예산·후보를 지정해도 자동으로 주문이 실행되지 않는다. 이 값은 "오늘의 터틀 확인" 카드(오늘 화면 → 관찰)가 55일 돌파·손절선·청산선을 계산할 때 참고용으로 쓰인다.
- 후보가 없으면 확인할 종목도 없다.
- 시세가 갱신되지 않은 후보는 평가에서 건너뛸 수 있다.
- 위성 종목의 실제 매도·추가매수 결정은 잠긴 터틀 자동주문 대신 **미션 4의 매매 계획**으로 한다.

### 미션 4 — 위성 보유분에 매매 계획을 일괄로 건다

이미 들고 있는 투더문(위성) 종목에는 "언제 팔지"가 아직 정해지지 않았을 수 있다. 오늘 화면의 **[일괄 계획 만들기]**(계획 없는 투더문 보유 섹션)를 눌러 강의 기본값(오늘가 기준·손절폭 7%·익절 3배·추세선 20일선·불타기 안 함)으로 한 번에 계획을 건다.

- 미리보기에서 종목별 상태를 확인한다: **정상 대기**(그대로 진행) / **이미 추세선 아래**(재돌파 후부터 적용되므로 첫날부터 "긴급"이 쏟아지지 않는다) / **시세 없음**(계획이 만들어지지 않음, 제외).
- 유선 계정·현금·이미 계획이 있는 종목은 자동으로 빠진다.
- 개별 종목만 다르게 하고 싶으면 체크를 해제하고 나중에 종목 검토 아코디언에서 따로 만든다.
- 코어 종목은 이 일괄 기능의 대상이 아니다(코어는 미션 1~2의 리밸런싱으로 관리).

### 미션 5 — 증권사에 손절 예약주문을 걸어 둔다

앱과 카카오톡은 손절선에 닿았다는 사실을 **알려줄 뿐 대신 팔아주지 않는다.** 계획을 만든 종목마다 실제로 쓰는 증권사 앱에서 손절선 가격에 "손절(스탑로스) 예약주문"을 걸어 둔다. 걸어 뒀으면 계획 카드의 `[등록했어요]`를 눌러 표시한다 — 미등록 종목은 오늘 화면의 "확인 필요" 섹션에 계속 남아 경고한다.

### 미션 6 — 카카오톡 알림을 연결한다 (선택)

앱을 하루 종일 열어 두지 않아도 손절선·익절선 도달과 추세선 이탈을 카카오톡으로 받고 싶다면, **설정 탭 → "카카오톡 알림"** 섹션의 5단계 체크리스트를 순서대로 따라간다(① 카카오 개발자 앱 만들기 → ② 스크립트 배포 → ③ 열쇠 입력 + 트리거 설치 → ④ 카카오 1회 동의 → ⑤ 앱에 연결). 상세 절차는 [카카오톡 알림 설정 가이드](카카오톡_알림_설정가이드.md)를 참고한다. 이 미션은 선택이며, 건너뛰어도 오늘 화면만으로 계획 기능을 전부 쓸 수 있다.

### 첫날 완료 체크

- [ ] 목표 총 자산과 코어/투더문 비중을 저장했다.
- [ ] 코어 카테고리 비중의 합계를 확인했다.
- [ ] 각 코어 카테고리의 대표 매수 종목을 지정하고 저장했다.
- [ ] 설정 탭에서 터틀 위성 예산을 저장했다.
- [ ] 위성 후보에만 🐢 표시를 붙였다.
- [ ] 코어와 위성을 어떤 원칙으로 관리할지 구분할 수 있다.
- [ ] 계획 없는 투더문 보유분에 일괄 계획을 만들었다(또는 왜 만들지 않았는지 안다).
- [ ] 계획을 만든 종목마다 증권사 손절 예약주문을 등록했다.
- [ ] 카카오톡 알림을 연결했다(또는 나중에 할지 결정했다).

## 2. 매일 8분 미션 — 보고, 계획하고, 기록한다

매일 같은 시간대에 한 번만 점검하는 것을 권장한다. **오늘 화면**은 로그인 후 기본으로 뜨는 탭이므로 앱을 열면 바로 보인다. 카카오톡 알림을 켜 뒀다면 대부분의 시간대는 카톡만 확인해도 되고, 이 루틴은 하루 한 번 앱에서 직접 정리·기록하는 시간이다.

### 0:00~5:00 — 오늘 화면 확인·처리

#### 1) 헤더부터 읽는다

상단 한 줄 요약("오늘 할 일 N건 — 풍산 전량 매도 · NAVER 절반 매도", 없으면 "오늘은 할 일이 없습니다. 기다리는 것도 계획입니다.")과 그 아래 **데이터 기준 시각**(예: `09-03 14:20 (장중)`)을 먼저 본다. 장중인데 시각이 오래됐으면 `[새로고침]`을 누른다 — 개장 중 30분, 장 마감 이후 미갱신이면 앱이 자동으로도 갱신하지만, 방금 막 확인하고 싶을 때는 직접 누르면 된다. 카카오톡 알림을 연결했다면 헤더의 상태 칩에서 마지막 동기화 시각과 "동기화 필요 N건" 여부도 함께 확인한다.

#### 2) 등급 순서대로 처리한다 — 긴급 → 오늘 실행 → 준비

| 등급 | 뜻 | 기본 표시 | 기본 태도 |
|---|---|---|---|
| **■ 긴급** | 손절선 도달, 또는 추세선이 확정 종가로 이탈 | 항상 펼침 | 가장 먼저 처리. 손절을 토론거리로 만들지 않는다 |
| **■ 오늘 실행** | 익절선 도달(절반 매도) | 항상 펼침 | 오늘 안에 처리 |
| **■ 준비** | 손절선 2% 이내 근접·다음 불타기선 근접·추세선 장중 이탈(종가 확인 대기) | 기본 접힘(건수 배지는 항상 보임) | 지금 당장 할 일은 없지만 미리 알아둔다 |

각 카드는 "현재가 vs 선 가격"과 수량을 한 줄로 보여주고, `[자세히]`를 누르면 손절선·익절선·추세선·불타기선 4개 선 전체와 계획 기준 시각·근거 고지가 펼쳐진다.

#### 3) 확인 필요 섹션을 비운다

- **시세 없음/오래됨**: 새로고침 후에도 계속 뜨면 종목 코드를 확인한다.
- **증권사 손절 예약주문 미등록**: 증권사 앱에서 손절선 가격으로 예약주문을 걸고 `[등록했어요]`를 누른다. 카카오톡은 알려줄 뿐 대신 팔아주지 않는다 — **손절 체결을 보장하는 것은 증권사 예약주문이지 카톡이 아니다.**

#### 4) 계획 없는 투더문 보유·대기 주문을 확인한다

- **■ 계획 없는 투더문 보유**: 위성 보유 중 아직 계획이 없는 종목이 있으면 `[일괄 계획 만들기]`로 한 번에 정리한다(첫날 미션 4와 동일한 마법사).
- **■ 대기 주문**: 리밸런싱·대청소의 처리 대기 카드(예전 "실행 큐" 화면이 그대로 옮겨온 자리). `[실행하기]`(체결 후 실제 체결일·체결가·수량 입력) / `[건너뜀]`(사유 필수) / `[내일]`(미룸) 세 가지 중 하나를 고른다. **터틀(위성) 신규 매수·불타기·손절·청산 주문은 현재 관찰 전용으로 잠겨 있어 이 섹션에 실행 카드로 뜨지 않는다** — 위성의 실제 매매는 계획 기능(위 2번)으로 한다.

#### 5) 관찰 섹션은 접어 둔 채로 배지만 본다

**■ 관찰**(기본 접힘)에는 일반 알림, 구루 신호, 과열 경고, "오늘의 터틀 확인"(55일 돌파 등 관찰용)이 참고 신호로 강등되어 모여 있다. 이미 활성 계획이 있는 종목은 여기서 "계획 기준 우선" 배지가 붙어, 같은 종목에 대해 "−5% 손절"(일반 알림)과 "−7% 손절선"(계획)이 동시에 뜨는 혼란을 줄인다 — 표시만 강등될 뿐 알림 계산 자체는 그대로 진행된다. 알림이 발화했으면 배지 옆 `[브리핑 보기]`로 상세를 연다.

### 5:00~8:00 — 대시보드에서 참고 신호 훑어보기

오늘 화면에 신호가 없거나 다 처리했으면, 더보기 → 대시보드로 이동해 구루 신호 엔진과 참고 지표를 마저 본다.

1. `🧭 구루 신호 엔진`에서 보유 종목의 매도 경고가 있는지 확인하고, 있으면 `왜 떴나`로 조건을 읽는다.
2. 구루 카드 아래 접힌 `📊 참고 지표`의 `과열 N` 배지를 확인한다 — `과열 0`이면 지나가고, `과열 1 이상`이면 펼쳐서 어떤 종목인지 본다.
3. 관찰 결과를 코어(대표 매수 종목·반기 리밸런싱)와 위성(관심종목에서 검토 후 🐢 지정 + 매매 계획)으로 분류한다. 방향이 불명확한 아이디어는 바로 매수하지 않고 주간 리플레이 목록에 넣는다.

과열은 "곧 폭락한다"는 뜻이 아니다 — **속도를 줄이고 근거를 다시 보라는 노란 신호등**이지 매도 버튼이 아니다.

### 매매 계획 만들기 — 4개 진입 경로

새 종목이나 계획 없는 보유 종목을 발견하면 아래 4곳 중 어디서든 계획을 만들 수 있다.

1. **새 매수 계획 화면**: 오늘 화면 상단 `[+ 새 매수 계획]` 또는 더보기 → "매매 계획 세우기". 종목 검색 → 현재가 자동 조회 → 계획 미리보기 → 관심종목에 저장하거나 지금 매수를 기록하며 저장.
2. **관심종목**: 아직 사지 않은 종목의 행 메뉴 "매매 계획"에서 미리 계획을 건다. 나중에 실제 매수를 기록하면 그 계획이 자산으로 자동 이전된다(기준가는 실제 체결가로 갱신).
3. **보유 종목**: 보유자산 탭 종목 검토 아코디언에서 계획을 만들거나 수정한다.
4. **매수 기록 시**: 신규 매수·추가매수 계산기 아래 "이 계획으로 저장" 체크(기본 켜짐) — 매수를 기록하는 김에 계획도 같이 만든다.

### 매도·추가매수 기록이 계획에 미치는 효과

계획이 있는 종목을 실제로 매도·추가매수하면, 그 기록이 계획 상태를 함께 갱신한다(자동매매가 아니라 — 기록 저장 버튼을 누르는 순간 같은 커밋으로 반영된다).

- **매도 기록**: 저장 화면에 "이 매도는 무엇인가"를 고르는 4가지 중 지금 신호에 맞는 것이 기본 선택되어 있다.
  | 선택 | 뜻 | 계획에 생기는 일 |
  |---|---|---|
  | 익절 절반 | 익절선 도달로 절반 매도 | 계획은 `active` 유지, 이후 같은 익절선은 다시 뜨지 않음 |
  | 손절 전량 | 손절선 도달로 전량 매도 | 계획 종료(`closed`, 사유 손절) |
  | 추세이탈 전량 | 추세선 이탈로 나머지 전량 매도 | 계획 종료(`closed`, 사유 추세이탈) |
  | 계획 무관 | 계획 신호와 상관없는 매도(예: 급전 필요) | 계획은 그대로 두고 기록만 남김 |
- **추가매수 기록(불타기)**: 불타기를 켠 계획에서만 의미가 있다. 저장 전에 4중 사전검사(현재가가 마지막 체결가보다 높은지, 새 손절선이 내려가지 않는지, 전량 손절돼도 손실이 한도 안인지, 총투입·종목 비중 한도를 넘지 않는지)를 통과해야 "N차"로 기록되고 손절선이 그만큼 위로 올라간다. 하나라도 실패하면 사유와 함께 차단되고 계획은 바뀌지 않는다.

### 결정 버튼 — 건너뜀·내일·3회 경고

계획 카드의 `[건너뜀]`을 누르면 사유를 반드시 고른다(현금 부족 / 이미 증권사에서 처리함 / 다시 생각해 보겠음 / 직접 입력). `[내일]`은 하루 미루는 것이다. **같은 신호를 3회 이상 미루면 카드에 경고 배지가 뜬다** — "3번째 미루고 있습니다. 계획을 바꿀지, 지킬지 지금 정하세요"라는 문구를 그냥 넘기지 말고, 이번 주 안에 계획을 수정하거나 실행한다. 긴급 손절을 건너뛰거나 미룰 때는 "손절은 끝이 아닙니다. 다시 오르면 다시 사면 됩니다 — 큰 손실만 피하면 됩니다"라는 도움말이 함께 뜬다.

### 카카오톡 알림 루틴 (연결한 경우)

카카오톡을 연결해 두면 앱을 안 열어도 아래 리듬으로 메시지가 온다 — 오늘 화면에서 확인하는 습관과 어긋나지 않도록 설계돼 있다.

- **개장 중 매시간(±15분)**: 손절선·익절선 도달, 불타기선(옵션, 기본 꺼짐)을 확인해 발송.
- **마감 확정 종가로 하루 1회**: 추세선 이탈만 그날의 확정 종가로 판정해 발송(장중에는 이동평균으로 오판하지 않기 위해 미룸).
- **아침 07:00**: 정숙시간(00:00~07:00 KST)에 보류된 메시지를 하나로 묶어 발송.
- **일일 요약(KR 마감 후)**: 신호가 없어도 "긴급 N · 오늘 실행 N · 준비 N · 확인 필요 N" 형태로 하루 1회 보낸다(생존 신호 — 스크립트가 살아 있다는 확인이기도 하다).

카톡 메시지의 버튼을 누르면 해당 종목이 포커스된 오늘 화면으로 바로 이동한다(딥링크). 카톡과 앱 화면이 다르게 보이면 문구 끝의 "계획 09-01 기준"과 앱의 "동기화 필요" 칩으로 어느 쪽이 최신인지 판단한다.

### 매일 완료 체크

- [ ] 오늘 화면 헤더에서 데이터 기준 시각을 확인했다.
- [ ] 긴급 → 오늘 실행 → 준비 순으로 계획 신호를 처리했다.
- [ ] 확인 필요(시세 문제·손절주문 미등록)를 비웠다.
- [ ] 계획 없는 투더문 보유가 있으면 일괄 계획을 만들거나 이유를 확인했다.
- [ ] 대기 주문(리밸런싱·대청소)을 실행·건너뜀·내일 중 하나로 처리했다.
- [ ] 신호를 보고 즉흥 매매를 하지 않았다.
- [ ] 처리하지 못한 신호는 건너뜀/내일로 기록하고, 3회 경고가 뜨면 계획을 다시 봤다.

## 3. 주간 30분 미션 — 신호 탐정 훈련

신호 리플레이는 **더보기 → 연구실 · 신호 리플레이**에서 연다. 목적은 "가장 수익률이 높은 숫자"를 찾는 것이 아니다. **내가 어떤 신호를 과신하는지, 어떤 좋은 구간을 반복해서 놓치는지 증거를 모으는 것**이다.

기능의 전체 설명은 [구루 신호 엔진 & 신호 리플레이 사용 설명서](사용설명서_구루신호엔진_신호리플레이.md)를 참고한다.

### 한 번의 복기 순서

#### 1) 이번 주의 종목 하나를 고른다 — 3분

우선순위는 다음과 같다.

1. 이번 주 오늘 화면에서 실제로 매도를 기록했거나 건너뛴/미룬 종목
2. 구루 신호와 과열 경고가 겹친 종목
3. 신호가 이상하다고 느낀 종목
4. 새로 터틀 후보에 넣고 싶은 종목

검색창 또는 보유·관심 종목 칩을 이용한다. 처음에는 한 번에 한 종목만 깊게 본다.

#### 2) 먼저 `리플레이(미래 숨김)`으로 본다 — 7분

미래를 모르는 상태에서 날짜를 이동하며 다음을 적는다.

- 이 시점에서 실제로 진입하고 싶었는가?
- 손절 위치와 감당 가능한 손실을 설명할 수 있는가?
- 구루 진단에서 정확히 어떤 조건이 충족됐는가?
- 가격기반 알림은 리플레이에서 검증 가능한 범위인가?

`이전 신호`와 `다음 신호`는 구루 신호 발생일 사이를 이동한다. RSI·골든크로스·데드크로스 등은 차트 마커가 아니라 `가격기반 알림 진단`에서 확인한다.

#### 3) `복기(미래 공개)`로 결과를 확인한다 — 7분

미래 차트를 공개한 뒤 다음 세 가지를 본다.

- 신호가 방향은 맞았지만 너무 빨랐거나 늦었는가?
- 신호 후 상승·하락이 일시적이었는가, 추세로 이어졌는가?
- 거래량, 이동평균선, RSI가 신호의 품질을 설명하는가?

리플레이는 현재 활성 규칙을 과거 가격에 다시 적용한 결과다. **그날 앱이 실제로 보낸 알림 기록은 아니다.**

#### 4) `내 판정`을 남긴다 — 5분

| 판정 | 사용하는 때 |
|---|---|
| `적절함` | 실행 가능한 시점에 의미 있는 신호였다 |
| `너무 빠름` | 방향은 맞을 수 있으나 확인이 부족했다 |
| `너무 늦음` | 움직임의 상당 부분이 끝난 뒤였다 |
| `잘못된 신호` | 후속 움직임이 신호의 의미를 지지하지 않았다 |
| `놓친 매수` | 좋은 매수 구간인데 신호가 없었다 |
| `놓친 매도` | 피할 만한 하락 구간인데 신호가 없었다 |

가능하면 짧은 메모를 붙인다.

```text
관찰: MA20 위였지만 거래량 증가가 없었음
판정: 너무 빠름
다음 확인: 거래량 동반 사례와 비교
```

날짜 전체뿐 아니라 특정 구루 규칙을 선택해 규칙별 판정을 남길 수 있다.

#### 5) 한 줄 결론만 쓴다 — 3분

다음 템플릿을 사용한다.

> 이번 종목에서 `[규칙명]`은 `[어떤 시장 상태]`에서는 유용했지만, `[어떤 조건]`에서는 오탐이 많았다. 다음 주에는 `[비교할 사례]`를 확인한다.

한 사례만 보고 규칙을 바꾸지 않는다. 다음 주 비교 질문 하나를 남기는 것으로 끝낸다.

#### 6) 기록을 백업한다 — 필요 시 5분

판정과 검증 사례는 브라우저 저장소에 보관된다. 중요한 기록은 화면 하단의 `내보내기`로 JSON 백업한다. 오래된 기록을 정리하기 전에도 먼저 내보내는 것이 안전하다.

### 4주 훈련 코스

| 주차 | 미션 | 성공 조건 |
|---|---|---|
| 1주차 | 마커와 `왜 떴나/안 떴나` 읽기 | 신호의 충족 조건을 말로 설명한다 |
| 2주차 | 큰 상승 구간의 매수 신호 평가 | 적절함·빠름·늦음을 구분한다 |
| 3주차 | 큰 하락 구간의 매도 경고 평가 | 경고와 실제 청산 주문을 구분한다 |
| 4주차 | 놓친 매수·매도와 오탐 비교 | 다음에 검증할 가설 하나를 만든다 |

### 샌드박스 사용 규율

규칙 샌드박스에서는 한 번에 조건 하나만 바꾼다.

1. 기준 규칙의 결과를 기록한다.
2. 조건 하나의 값 또는 on/off만 변경한다.
3. 좋아진 사례뿐 아니라 나빠진 사례도 확인한다.
4. 다른 종목과 다른 시장 구간에서 다시 확인한다.
5. 검증 사례를 저장한다.

샌드박스 값은 미리보기이며 라이브 구루 신호·알림·저장된 규칙을 바꾸지 않는다. 유리한 구간 하나에 맞춘 값은 발견이지 결론이 아니다.

## 4. 월간 15분 미션 — 시스템 건강검진

월말에는 수익률보다 **내가 시스템을 제대로 실행했는지**를 먼저 본다.

### 1) 실행 규율 점검

- 오늘 화면의 계획 신호(긴급·오늘 실행)나 대기 주문(리밸런싱·대청소)을 이유 없이 방치한 적이 있는가?
- `내일`을 반복한 신호·주문은 무엇인가? 같은 신호를 3회 이상 미뤄 경고 배지가 뜬 종목이 있었는가?
- `건너뜀` 사유가 같은 이유로 반복되는가?
- 매도·추가매수 기록의 실제 체결가·수량을 정확히 입력했는가?
- 긴급(손절선 도달·추세선 이탈) 신호를 다른 신호보다 늦게 처리하지 않았는가?

반복되는 건너뜀은 의지 부족이 아니라 예산, 계좌, 후보 구성 또는 생활 리듬의 문제일 수 있다.

### 2) 위성·계획 설정 점검

- 총자산이 크게 변했다면 설정 탭에서 터틀 위성 예산을 다시 계산해 저장한다.
- 🐢 후보가 여전히 위성 전략에 적합한지 확인한다.
- 코어 자산에 🐢가 잘못 붙어 있으면 해제한다.
- 계획 없는 투더문 보유가 다시 쌓였으면 일괄 계획 만들기로 정리한다.
- 손절 예약주문 미등록 종목이 남아 있지 않은지 확인 필요 섹션을 훑는다.
- 가격 데이터가 반복해서 부족한 종목은 데이터 경로를 점검한다.

### 3) 연구 기록 점검

- `놓친 매수/매도 모아보기`에서 반복 패턴을 찾는다.
- 같은 규칙에 `잘못된 신호`가 누적되는지 본다.
- 표본이 적은데 성과 숫자만 보고 결론 내리지 않았는지 확인한다.
- 다음 달에 집중할 규칙 또는 종목을 하나만 고른다.

### 월간 점수판

수익률이 아니라 과정에 점수를 준다.

| 항목 | 1점 조건 |
|---|---|
| 관찰 | 정한 날의 오늘 화면·대시보드 점검을 빠뜨리지 않았다 |
| 실행 | 모든 계획 신호·대기 주문에 결정을 남겼다 |
| 기록 | 주간 판정과 메모를 남겼다 |
| 분리 | 참고 신호로 직접 주문하지 않았다 |
| 동결 | 단기 성과 때문에 설정을 즉흥 변경하지 않았다 |

`4~5점`: 루틴 유지.

`2~3점`: 시간을 줄이더라도 핵심 루틴부터 복구.

`0~1점`: 새 전략을 추가하지 말고 실행 가능한 구조부터 다시 설계.

## 5. 반기 60분 미션 — 코어 리밸런싱 데이

코어 자산을 사고파는 공식 점검 시간이다. 평소 구루 신호나 과열 경고로 코어 비중을 흔들지 않고, 반기 점검에서 저장된 목표와 밴드를 사용한다.

### 1단계 — 목표를 검토한다

1. `목표 총 자산 (KRW)`을 현재 계획에 맞게 갱신한다.
2. `① 전략 배분 — 코어 vs 투더문`을 검토한다.
3. `② 코어 자산배분 — 카테고리별` 목표를 검토한다.
4. 변경했다면 `저장하기`를 누른다.

단기 시장 전망만으로 목표 비중을 바꾸지 않는다. 목표 변경에는 생활자금, 투자 기간, 감당 가능한 변동성처럼 장기적인 이유가 있어야 한다.

### 2단계 — 대표 매수 종목을 점검한다

`③ 대표 매수 종목 지정`에서 각 카테고리를 확인한다.

- 부족한 카테고리: 지정된 대표 종목으로 매수 주문을 만들 수 있다.
- 초과한 카테고리: 실제 보유 종목을 기준으로 매도 주문을 만든다.
- 대표 종목 미지정: 해당 카테고리의 매수 주문은 스킵된다.

변경했다면 다시 `저장하기`를 누른다.

### 3단계 — 밴드를 읽는다

현재 자동 주문 대상은 **`② 코어 카테고리`의 목표 대비 ±5%p 밴드 이탈**이다.

- `① 전략 배분(코어/투더문)` 이탈 자체는 현재 주문 생성 대상이 아니다.
- 모든 코어 카테고리가 밴드 안이면 주문 0건이 정상이다.
- 밴드 이탈 안내는 먼저 보여주는 참고 정보이고, 실제 종목·수량은 다음 단계에서 계산된다.

### 4단계 — `리밸런싱 주문 생성`을 누른다

저장된 목표를 기준으로 주문을 생성한다. 결과가 생성되면 **오늘 화면의 "대기 주문" 섹션**으로 이동한다.

| 결과 | 의미 | 조치 |
|---|---|---|
| 주문 N건 생성 | 실행 가능한 리밸런싱 카드가 오늘 화면 대기 주문에 추가됨 | 오늘 화면에서 실제 체결값 입력 |
| 모두 밴드 안 | 지금 조정할 것이 없음 | 정상 종료 |
| 대표 매수 종목 미지정 | 부족한 카테고리의 매수 도구 없음 | ③에서 지정 후 저장 |
| 가격 확보 실패 | 종목 가격을 가져오지 못함 | 티커·거래소·시세 확인 |
| 환율 미지원 | 원화 조정액을 종목 통화로 계산 불가 | 종목 통화·환율 확인 |
| 매도할 코어 보유 없음 | 초과 카테고리에 실제 매도 대상이 없음 | 자산 분류 확인 |
| 조정액이 1주 미만 | 필요한 조정 규모가 너무 작음 | 정상 대기 |
| 이미 대기 중 주문 있음 | 중복 생성을 차단함 | 오늘 화면의 기존 대기 주문부터 처리 |

### 5단계 — 오늘 화면 "대기 주문"에서 마무리한다

`REBALANCE_BUY`와 `REBALANCE_SELL` 카드의 목표, 종목, 수량을 다시 확인한다. 증권사에서 체결한 뒤 `실행하기`를 통해 실제 체결일·체결가·수량을 입력한다.

세금, 거래 가능 시간, 계좌별 보유 상태는 앱 바깥의 실제 조건이므로 주문 전 최종 확인한다.

### 반기 완료 체크

- [ ] 목표 총 자산과 비중을 검토하고 저장했다.
- [ ] 대표 매수 종목의 티커와 거래소를 확인했다.
- [ ] 미저장 변경이 없는 상태에서 주문을 생성했다.
- [ ] 주문 0건의 이유를 정상·오류·미설정으로 구분했다.
- [ ] 생성된 주문을 오늘 화면 대기 주문에서 실제 체결값으로 처리했다.
- [ ] 단기 전망 때문에 목표를 즉흥적으로 바꾸지 않았다.

## 6. 실전 상황 카드

### 상황 A — 구루 매도 경고와 과열 경고가 동시에 떴다

**올바른 행동**

1. `왜 떴나`에서 각각의 조건을 확인한다.
2. 보유 목적이 코어인지 위성인지 구분한다.
3. 위성이면 그 종목에 매매 계획이 있는지 확인한다 — 있으면 오늘 화면에서 "계획 기준 우선" 배지가 붙어 있을 것이고, 손절선·추세선 상태를 그 카드로 판단한다.
4. 코어이면 반기 리밸런싱 원칙과 밴드를 유지한다.
5. 주간 리플레이 후보로 기록한다.

**피할 행동:** 두 경고가 겹쳤다는 이유만으로 즉시 전량 매도.

### 상황 B — 구루 매수 후보는 있는데 오늘 화면에는 아무 신호도 없다

**해석:** 오늘 화면의 등급(긴급/오늘 실행/준비)은 **매매 계획이 있는 종목에만** 뜬다. 구루 카드는 관찰 후보일 뿐이라 계획이 없으면 조건이 아무리 좋아 보여도 오늘 화면·카카오톡 어디에도 신호가 생기지 않는다.

**올바른 행동:** 위성 후보로 적합한지 검토한 뒤, 🐢 지정 여부를 확인하고 그 종목에 매매 계획을 직접 만든다(§2 "매매 계획 만들기 4개 진입 경로"). 계획을 만들지 않으면 계속 조용하다.

### 상황 C — "오늘의 터틀 확인"(관찰)에 55일 돌파가 떴다

**해석:** 터틀 자동주문(신규 진입·불타기·손절·청산)은 현재 관찰 전용으로 잠겨 있다. 이 카드는 참고로 알려주는 것이지 실행 버튼이 달린 주문이 아니다.

**올바른 행동:** 돌파를 근거로 실제 매수하고 싶으면 그 종목에 매매 계획을 새로 만들어 손절선·익절선을 직접 정한다.

**피할 행동:** 카드에 실행 버튼이 없다고 앱이 고장났다고 오해하거나, 실행 버튼을 찾으려 다른 화면을 헤맨다.

### 상황 D — 오늘 화면 "긴급"에 손절선 도달이 떴다

**올바른 행동:** 다른 신호보다 우선하여 처리한다. `[매도 기록]`으로 전량 매도를 기록하거나, 이미 증권사 예약주문으로 처리됐으면 `[건너뜀]`으로 사유를 남긴다. 실행하지 못했다면 침묵하지 말고 `[내일]`로 기록한다.

**피할 행동:** 반등을 기다리며 `[내일]`을 반복한다 — 같은 신호를 3회 이상 미루면 경고 배지가 뜬다.

### 상황 E — 리밸런싱 주문이 한 건도 없다

**확인 순서**

1. 목표 총 자산과 코어 비중이 저장됐는가?
2. 코어 카테고리가 ±5%p 밴드를 벗어났는가?
3. 부족한 카테고리에 대표 매수 종목이 있는가?
4. 가격·환율·보유 데이터가 있는가?
5. 같은 주문이 이미 오늘 화면 "대기 주문"에 있는가?

모두 밴드 안이라면 아무것도 하지 않는 것이 정답이다.

### 상황 F — 리플레이에서 놀라운 설정값을 찾았다

**올바른 행동:** 기준 결과를 저장하고, 다른 시기·다른 종목·불리한 구간에서 반복 검증한다.

**피할 행동:** 한 종목의 가장 좋은 구간에 맞춰 파라미터를 계속 조정한다.

### 상황 G — 참고 지표는 위험한데 가격은 계속 오른다

**해석:** 과열 경고는 꼭지 예측이 아니다.

**올바른 행동:** 신규 추격 여부를 더 신중히 보고, 기존 포지션은 정해 둔 매매 계획(손절선·추세선)으로 관리한다.

### 상황 H — 며칠 동안 앱을 열지 못했다

**해석:** 신호와 주문은 사라지지 않는다. 오늘 화면의 대기 주문(리밸런싱·대청소)은 Drive에 저장되어 처리할 때까지 대기하며 밀린 만큼 에스컬레이션 표시로 강조된다. 매매 계획의 손절선·익절선은 카카오톡을 연결해 뒀다면 앱을 못 연 동안에도 매시간 확인·발송됐을 것이다.

**올바른 행동:** 앱을 열면 오늘 화면부터 확인한다 — 긴급·오늘 실행 등급을 먼저 처리하고, 대기 주문은 에스컬레이션된 것부터 처리한다. 리밸런싱 카드가 필요하면 `리밸런싱 주문 생성`으로 오늘 기준 재평가한다.

**피할 행동:** 밀렸다는 이유로 신호나 대기 주문을 사유 없이 계속 방치한다.

## 7. 12개월 운용 규율

1. **기능의 권한을 섞지 않는다.** 참고는 참고, 연구는 연구, 계획은 계획, 실행은 오늘 화면이다.
2. **코어와 위성을 섞지 않는다.** 코어는 리밸런싱, 위성은 매매 계획(터틀 자동주문은 관찰 전용 잠금)으로 관리한다.
3. **손절을 토론거리로 만들지 않는다.** 오늘 화면 "긴급"에 뜬 손절선 도달은 우선 처리한다.
4. **신호가 없는 날을 견딘다.** 신호를 만들기 위해 후보나 조건을 억지로 바꾸지 않는다.
5. **한 사례로 규칙을 바꾸지 않는다.** 여러 종목과 시장 구간에서 반복성을 확인한다.
6. **샌드박스를 라이브 설정으로 착각하지 않는다.** 샌드박스는 연구 메모다.
7. **대표 매수 종목을 자주 교체하지 않는다.** 카테고리 목적이 변한 경우에만 재검토한다.
8. **미실행을 숨기지 않는다.** 건너뜀 사유와 연기 기록을 남긴다.
9. **실제 체결값을 기록한다.** 기준가와 체결가는 다를 수 있다.
10. **성과보다 과정부터 평가한다.** 한 달 수익률보다 정해진 루틴 준수 여부를 먼저 본다.

### 백테스트로 확정된 파라미터의 동결 목록

앞으로 6~12개월 동안 아래 변경은 하지 않는다. 성과가 좋아 보여도, 나빠 보여도 마찬가지다.

- **금지**: 유닛 확대(2→3 이상), 위성 비중 확대(10% → 20~30%), 전 종목 터틀 적용, 코어 자산(니케이·QQQ 등)의 터틀 전환.
- **유일한 예외**: 연패가 정말 견디기 힘들 때 유닛 축소(2→1). 시스템을 포기하는 것보다 낫다.

1년 뒤, 오늘 화면·매매 계획에 쌓인 실제 실행·건너뜀 기록과 체감을 근거로 재판단한다.

## 9. 인쇄용 한 장 체크리스트

### 매일 8분

- [ ] 오늘 화면 헤더의 데이터 기준 시각 확인, 오래됐으면 새로고침
- [ ] `■ 긴급` → `■ 오늘 실행` → `■ 준비` 순서로 계획 신호 처리
- [ ] `■ 확인 필요`(시세 문제·손절주문 미등록) 비우기
- [ ] `■ 계획 없는 투더문 보유` 있으면 일괄 계획 만들기
- [ ] `■ 대기 주문`에서 `오늘 주문 생성` 후 실행·건너뜀·내일 결정(0건이면 `왜 주문이 없나요?` 확인)
- [ ] `■ 관찰`에서 구루 신호 매도 경고와 `과열 N` 확인
- [ ] 신호를 보고 즉흥 매매를 하지 않았는지, 3회 경고가 뜬 항목은 없는지 확인

### 매주 30분

- [ ] 이번 주 종목 하나 선택
- [ ] 미래 숨김 모드에서 먼저 판단
- [ ] 미래 공개 후 결과 비교
- [ ] 판정 1개와 메모 저장
- [ ] 다음 주 검증 질문 하나 작성

### 매월 15분

- [ ] 반복 건너뜀·연기 사유 확인
- [ ] 설정 탭에서 위성 예산과 🐢 후보 확인
- [ ] 계획 없는 투더문 보유·손절주문 미등록 재정리
- [ ] 놓친 매수·매도 반복 패턴 확인
- [ ] 중요한 판정·사례 JSON 백업

### 반기 60분

- [ ] 목표 총 자산과 전략 비중 검토
- [ ] 코어 카테고리 비중 검토
- [ ] 대표 매수 종목과 거래소 확인
- [ ] 저장 후 리밸런싱 주문 생성
- [ ] 생성 결과 또는 0건 사유 확인
- [ ] 오늘 화면 대기 주문에서 실제 체결값 입력

## 10. 마지막으로 기억할 세 문장

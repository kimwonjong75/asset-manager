# 기능 정비 가이드 — 투자 스타일 × 백테스트 결과 (2026-07-26)

## 0. 이 문서의 근거

- **투자 스타일 (사용자 확인, 2026-07-26)**: ①알림은 극소수 고확신만(하루 0~3건) ②손실 60종목은 검토 큐로 매주 몇 개씩 ③매수 축은 터틀 편입 + 관심종목 감시 + 코어 지수 적립만(개별주 매수추천 축소) ④앱 확인 리듬은 매일 5~10분
- **백테스트 (2010-2019 개발 / 2020-2022 검증, 한국 전종목 3,858개)**: `docs/backtest/RESULTS_*` 4개 문서
- **핵심 제약**: 잠금표본(2023-2025) 미개봉 상태 → 모든 채택은 "잠정"이며 G8·G11 통과 후 최종 확정

## 1. 설계 원칙 — "신호 예산제"

현재 앱은 매도규칙 13종 전부 기본 ON이고, P4 측정 결과 **보유일의 91%에서 이미 경보가 발동** 중이다(첫 경보까지 중앙값 0거래일). 매일 5~10분 사용자에게 이것은 정보가 아니라 소음이며, "실행이 문제"라는 진단의 직접 원인이다.

> **원칙: 알림은 하루 0~3건 예산 안에서만 발화한다. 검증된 신호가 예산을 우선 배정받고, 미검증 신호는 기본 OFF로 내린다.**

P4의 "신규 신호 증분가치 없음" 결론은 **13종 전부 ON인 포화 상태 기준**이다. 포화를 해소하면(미검증 규칙 OFF) 검증된 신호가 고확신 층으로 기능한다 — 결론이 반대로 적용된다는 점이 이 가이드의 핵심 논리다.

## 2. 기능별 판정표

### 2-1. 매도 신호 (기존 13종 + 검증 신규)

| 판정 | 대상 | 근거 |
|---|---|---|
| **ON 유지·승격** | 급성매도 6종(1개월+100% / 1주+40% / 상한가 / 갭+음봉+거래량 / 투매클라이맥스(프록시) / −5%+거래량2배) — **신규 구현 필요** | 유일하게 자체 검증 통과(검증표본 63일 시장초과 −5~−12%p, Holm 유의, 연도 강건). 발화 빈도가 낮아(희귀 이벤트) 신호 예산과 부합 |
| **ON 유지** | climax-top, distribution-high | 미검증이지만 급성신호와 같은 "과열 붕괴" 계열이고 발동률이 낮음. 구루 지식과 정합 |
| **기본 OFF로 강등** | stop-loss(−5%), dead-cross, trend-break, long-decline | **포화 주범**(발동률 57%/52%/39%/43%). 개별 유효성 미검증. 강의·P4 모두 데드크로스류의 신호 가치에 부정적. ※끄는 이유는 "검증 실패"가 아니라 "미검증+포화"임 — 소수 종목만 들고 손절 규율이 필요해지면 재활성 가능 |
| **완화 또는 OFF** | swing-low-break(24%), ma120-break, weinstein-150-break, daily-crash 단독, overheat-drop, overheat-profit, profit-target | 발동률·중복도 대비 미검증. profit-target(+20%)은 알림보다 "터틀 청산 규칙"과 역할 중복 |
| **OFF 유지** | strong-sell-signal | 이미 기본 OFF, 백엔드 의존 |
| **보류(선택)** | 보유열화 H3(변동성 급증) | REVIEW_WARNING 통과했으나 급성 6종과 92.7% 중복 — 예산 관점에서 후순위 |
| **도입 안 함** | H4 윗꼬리 누적, H5 붐버스트, 코스피 150/200일선 레짐 | H4·H5 검증 미달, 레짐은 REJECTED(방향 반대) |

### 2-2. 매수 신호

| 판정 | 대상 | 근거 |
|---|---|---|
| **유지 (유일한 매수 경로)** | 터틀 55일 돌파 편입 + 불타기 | 자체 강건성 검증 완료된 기존 체계. 사용자 주력 목표 |
| **유지 (라벨 교정)** | 구루 buy-watch 3종(눌림목/고점근접/20일선 회복) | "추천"이 아니라 **"관찰 알림"** 라벨로. 관심종목 감시 용도로만 |
| **폐기 확정** | rule-rs-90-screening, rule-ma-pullback-entry (draft 2종) | RS90 모멘텀 매수 자체가 검증 실패(진입 코호트 126일 중앙 −13%, 품질필터 미확증). draft 사문화 상태를 정식 폐기로 |
| **매수 근거 제거** | 런치패드(maCompression) | **역방향 유의**(수렴 후 돌파가 오히려 −5%p). 수치 표시는 무해하나 "매수 기회" 문구·가점은 제거 |
| **강화** | 코어 지수 적립 리마인드 | 사용자 선택. 90/10 전환 계획과 정합. DAA는 미채택(아래) |

### 2-3. 자산배분

- **정적 90/10 + 터틀 유지.** DAA(채권 동적배분·듀얼모멘텀)는 백테스트에서 2022 채권 폭락 회피는 확인됐으나 MDD<10% 목표 미달, 전 전략이 SPY 미달, 코로나 급락 회피 실패. 월 1회 리밸런싱 리듬도 사용자와 불일치(매일 5~10분 형). **도입 안 함** — 향후 원하면 별도 재검토.

### 2-4. 손실 60종목 — 신규 보완 기능 (최우선)

사용자 선택: 주간 검토 큐. 설계 방향:
- 주 1회(예: 토요일) **"이번 주 검토 2~3종목"** 큐 생성. 우선순위 = 검증된 신호 이력(급성신호 발화 이력 있는 종목 우선) + 손실률 + 보유 비중
- 각 종목에 4치 점검 카드(기존 종목검토 아코디언 재사용) + "왜 이 종목이 이번 주인가" 사유
- **결정은 항상 사용자** — 앱은 매도 실행 없음. 결정 이력만 기록
- 예상 소진: 주 2~3종목 × 20주 ≈ 손실 60종목 반년 내 전수 검토

## 4. 하지 않기로 한 것 (명시)

- 자동매도·자동실행 일체
- DAA 도입, 90/10 변경
- RS 런타임 엔진 구축 (RESEARCH_ONLY 등급에 백엔드 공사 불요)
- 미국 규칙 선반영 (PIT 데이터 확보 전)
- 코스피 지수 레짐 배지 (REJECTED)

## 5. 재검토 트리거

- G8·G11 통과 → 잠금표본(2023-2025) 최종 확인 → 채택 신호 재확정

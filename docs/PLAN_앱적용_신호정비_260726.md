## 1. 배경: 세 결과가 가리키는 하나의 그림

1. **한국**: 급성매도 6종만 2단계(개발→검증) 검증을 통과했다(63일 시장초과 −5~−12%p, Holm p<0.005, 연도 강건, 상위기여 제거 후 방향 유지). 시장레짐·런치패드는 기각, RS 품질은 미확증.
2. **앱 현황(P4 실측)**: 기존 매도규칙 13종이 보유 평가일의 **91%에서 이미 경보 발동** 중(첫 경보까지 중앙값 0거래일). 이 포화 상태에 신규 신호를 얹으면 95%가 기존과 같은 날 겹쳐 증분이 없다.
3. **미국(약식)**: 거래량 축의 방향이 한국과 **4구간 단조 대칭으로 정반대**. 한국 검증 신호를 미국 종목에 이식하면 역효과 위험.
4. **사용자 스타일(확인 답변)**: 매일 5~10분, 알림은 하루 0~3건 고확신만, 손실 60종목은 주간 큐, 매수는 터틀+관찰+코어 적립만.

→ 결론: **"신호 추가"가 아니라 "신호 교체"가 과제다.** 미검증·고빈도 규칙이 차지한 알림 예산을 회수해 검증·저빈도 신호에 재배정한다.

## 2. 단계별 계획

### Phase 0 — 신규 구성 선검증 (필수 게이트, 코드는 리서치만)

**이 계획의 자기 지적**: P4는 "기존 13종(C) vs 기존+신규(D)"만 비교했다. 우리가 실제 배포하려는 구성 — **"포화 4종 OFF + 검증 6종 ON"(C′)** — 은 백테스트된 적이 없다. 기본값을 뒤집기 전에 검증한다.

- 기존 P4 하네스(`scripts/backtest/lectureSignals/appRules.ts`, `runIncremental.ts`) 재사용, 앱 코드 무접촉

**C′ 후보 구성 (외부 검토 반영 — 사전 고정, 모호성 제거)**

| 구성 | ON 목록 | 근거 |
|---|---|---|
| C (현행) | 기존 13종 전부 | 비교 기준선 |
| **C′-min (주 후보)** | 급성 6종(S1·S2·S3·S4·S5프록시·S6) + climax-top + distribution-high = **8종** | GUIDE §2-1 판정표와 정합(weinstein/ma120/swing-low는 "완화 또는 OFF" 분류) |
| C′-mid (비교용) | C′-min + weinstein-150-break + ma120-break + swing-low-break = 11종 | 이동평균 이탈 계열을 남길 경우의 예산 소모 측정 |

**판정 지표 (외부 검토 반영 — "비율"이 아니라 "하루 알림 건수")**

사용자 목표는 "발동일 비율"이 아니라 **하루 실제 알림 수(0~3건)**다. 보유 60종목이면 발동일 비율 20%도 하루 12건일 수 있으므로 비율 기준을 폐기하고 다음으로 대체:
- **일평균 신규 알림 건수**: 포트폴리오 기준, "신규 전이"(어제 미충족→오늘 충족) 건수/일. 상태 지속 건수(그날 충족 상태인 종목·규칙 수)도 참고로 병기 — 앱 알림 체감은 신규 전이에 가깝고, 91% 수치는 상태 기준이었음을 명시
- **최대 스파이크**: 하루 최대 알림 건수(급락장 몰림 측정)
- 측정 포트폴리오: 무작위 KR 포트폴리오 표본(60종목×200세트, 시드 고정) 주분석 + 30종목·10종목 규모 민감도. (실보유 스냅샷은 Drive 개인 데이터라 리서치 트리에서 미사용)
- 성과 지표: 트리거 후 63일 성과, 하위10% 손실 회피, 오탐율 (C vs C′ 비교)

- **통과 기준(사전 고정)**: 60종목 포트폴리오 기준 C′-min의 **일평균 신규 알림 ≤ 3건**, 그리고 하위10% 손실 회피가 C 대비 3%p 이상 악화되지 않을 것
- 미통과 시: 기본 OFF 목록을 조정하고 재실행(조정 이력을 결과 문서에 기록 — 이 단계는 탐색이 허용되는 운영 설계 단계이며, 신호 자체의 채택 검증이 아님을 명시)

### Phase 0-B — 게이트 B 재설계 (사후 수정, 2026-07-26 사용자 승인)

> **⚠ 사후 수정 고지 (편향 위험 명시)**: 아래 기준은 **1차 실행 결과를 본 뒤** 개정한 것이다. 결과를 보고 기준을 바꾸는 것은 연구자 자유도(researcher degrees of freedom) 남용 위험이 있다. 이를 상쇄하기 위해 ①원 기준과 새 기준의 판정을 **둘 다 병기**하고 ②C′-min이 탈락 가능한 **적대적 조건**을 새로 추가한다(B′-3). 이 절은 신호 자체의 채택 검증이 아니라 **운영 구성 설계**이며, 급성 6종의 검증 등급(REVIEW_WARNING)은 이 절과 무관하게 이미 확정된 값이다.

**원 게이트 B의 결함 (개정 사유)**

원 기준은 "하위10% 손실 회피"만 측정하고 그 회피를 얻기 위해 지불한 비용을 차감하지 않았다. 무한정 매도하는 정책은 정의상 꼬리위험을 항상 줄이므로, 이 기준은 **과잉매매를 구조적으로 보상**한다. 1차 실행 실측이 이를 확인했다: 현행 C는 하위10%를 25%p 개선하지만 창당 10.5회 매도·누적 거래비용 8.4%를 치르고 평균 수익률이 HOLD 대비 7.7%p 악화됐다(−8.31% vs −0.62%).

**게이트 B′ (개정, 사전 고정 — 실행 전 확정)**

기준선을 C가 아니라 **HOLD(아무 알림도 실행하지 않는 방치 상태)**로 바꾼다. 사용자의 실제 대안은 "완벽 실행되는 C"가 아니라 "실행되지 않아 방치되는 C"에 가깝기 때문이다.

| 코드 | 기준 | 판정 셀 |
|---|---|---|
| **B′-1 (수익 보존)** | 평균 및 중앙 수익률이 HOLD 대비 1%p 넘게 악화되지 않을 것 | 2코호트 × 2표본 = 4셀 전부 |
| **B′-2 (꼬리 개선)** | 하위10% 손실이 HOLD 대비 3%p 이상 개선될 것 | 4셀 전부 |
| **B′-3 (적대적 조건, 신규)** | C′-min이 **예산제한 C**(C를 하루 최대 3건으로 제한해 실제 실행 가능하게 만든 버전)보다 열등하지 않을 것 — 평균 수익률과 하위10% 양쪽에서 | 4셀 전부 |

- **B′-3의 취지**: 개정 기준이 C′-min에 유리하게만 설계되는 것을 막는 장치다. 현행 규칙 집합도 예산 제한을 걸면 실행 가능해지므로, "규칙을 교체할 필요 없이 개수만 제한하면 되는 것 아닌가"라는 반론을 정면으로 시험한다. **C′-min이 여기서 지면 규칙 교체의 근거가 사라진다.**
- 예산제한 C 구현: 하루 발동 건수가 3건을 초과하면 우선순위로 상위 3건만 실행(우선순위 규칙은 severity 순 → 동률 시 종목코드 오름차순, 결정론). 실행되지 않은 신호는 그날 소멸(이월 없음) — 실제 사용자가 놓치는 상황의 근사
- **개발표본(2010-2019)을 판정에 포함**한다. 개정 기준은 검증표본 결과를 보고 만들었으므로, 개발표본이 이 결정에 대한 유사 표본외 확인 역할을 한다
- 원 게이트 B 판정도 결과 문서에 계속 병기한다(숨기지 않음)

## 3. 근거 사슬 (검토자용)

### 3-1. R1(급성 6종 신설)이 정당한 이유
- 사전등록(`PREREG_강의가설_통합백테스트계획.md` §7) → 개발표본 확정 → 검증표본 1회 실행 순서를 지켰고, 7변형 전부 방향 일치·Holm 유의·REGIME_CONCENTRATED 아님·상위기여 제거 후 방향 유지
- S5의 앱 이식 문제(원천 거래대금 부재)는 3자 비교로 해소: 조정/무조정 프록시 Jaccard 100%, 원천 대비 효과크기 차이 0.2%p 미만, 등급 동일
- 거래 반사실 A/B에서 다음시가 매도가 하위10% 손실을 대폭 축소(예: S1 보유 −44.3% vs 매도 −4.5%)

### 3-2. R2(기존 4종 OFF)는 "검증"이 아니라 "운영 판단"이다 — 구분 명시
- 이 4종이 **틀렸다는 백테스트는 없다.** P4가 측정한 것은 발동률(57%/52%/39%/43%)과 결합 포화(91%)다
- OFF의 근거는 ①미검증 ②포화로 인한 변별력 상실 ③사용자의 명시적 알림 철학(0~3건/일). 삭제가 아닌 기본값 변경이므로 가역적
- 이 구분을 흐리면 안 됨: "백테스트로 기각됨"이라고 표현하지 말 것

### 3-3. R3(Phase 0)가 필요한 이유 — 이 계획의 가장 약한 고리 자백
- P4의 C/D 비교는 제안 구성 C′를 다루지 않았다. "OFF+ON 교체 후 포화가 실제로 해소되는지, 손실 회피가 유지되는지"는 현재 **측정되지 않은 주장**이다
- 따라서 Phase 1 착수 전 Phase 0 통과를 하드 게이트로 둔다. 이 게이트 없이 기본값을 뒤집으면 이 계획도 강의와 같은 "그럴듯한 미검증 주장"이 된다

### 3-4. R6(KR 게이팅)의 근거
- 미국 약식에서 거래량 축이 한국과 정반대(4구간 단조 대칭: 한국 −7→−19% vs 미국 +0.9→+3.5%)
- 약식 결과는 생존편향이 있어 미국 신호 **도입** 근거로는 부족하지만, 한국 신호를 미국에 **이식하지 말아야 할** 근거로는 충분(방향 반전 리스크가 실측됨)

### 3-5. 남은 한계 (검토자가 지적하기 전에 명시)
1. 잠금표본(2023-2025) 미개봉 → 모든 채택은 잠정. G8(합병대가)·G11(KRX 교차검증, 사용자 키 발급 필요) 통과 후 최종 확정
2. 126/252일 경제성은 배당 미반영(`PRICE_RETURN_EX_DIVIDEND`) — 주지표는 63일이라 영향 제한적이나 장기 해석은 조건부
3. 백테스트↔앱 런타임 데이터 불일치 가능성: 앱 `/history`의 조정 여부 미확인. S5는 3자 비교로 면역 확인했으나, S1~S4·S6은 분할 경계일에 오발화 가능 → Phase 1 parity 테스트에 분할 경계 케이스 포함 필수
4. 매칭 대조군의 잔차 모멘텀 — 관측 효과는 조건부 상관이며 인과 아님
5. 미국 약식의 생존편향 — 해당 문서 최상단 경고 참조

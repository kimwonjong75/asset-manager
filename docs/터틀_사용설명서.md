<a id="summary"></a>
## ① 한 장 요약

터틀은 보유 종목을 **팔 때**·**다시 살 때**를 매일 자동으로 계산해 주는 규칙입니다.

- **앱이 하는 일**: 매일 종가로 선을 계산하고, 왜 그 선인지 한 줄로 알려줍니다.
- **사용자가 하는 일**: 증권사에서 실제로 사고팔고, 앱에 [팔았음 기록]·[샀음 기록]을 남깁니다.
- **앱이 하지 않는 일**: 자동 주문. 터틀은 계산·알림만 합니다.

규칙은 단순합니다.

```
보유 종목 종가가 {{exitLookback}}일 최저가 이하로 마감 → "팔 때"
  → 팔면 자동으로 "다시 살 때 감시" 명단에 등록
감시 종목 종가가 {{entryLookback}}일 최고가 위로 마감 → "다시 살 때"
  → 사면 손절가·다음 불타기가가 같이 계산됨
```

<a id="routine"></a>
## ② 매일 5분 루틴

1. **아침 카톡 요약**을 확인합니다(연결했다면). "오늘 할 일" 종목명과 건수만 짧게 옵니다.
2. **홈**을 열어 맨 위 [터틀 오늘 할 일] 카드를 봅니다. 자세한 읽는 법은 다음 절 [터틀 오늘 할 일 카드 읽는 법](#today)을 봅니다.
3. 카드에 있는 종목을 순서대로 처리합니다 — 팔 때 → 다시 살 때 → 추가 매수 → 손절선 확인.
4. 카톡을 안 켜 놨다면, 장 마감 후 한 번 더 홈을 열어 확인합니다.

이 루틴 말고는 할 일이 없습니다. 카드가 비어 있으면 "오늘 할 일 없음"이 뜨고, 그게 정상입니다.

<a id="today"></a>
## [터틀 오늘 할 일] 카드 읽는 법

홈 맨 위, 파란 테두리 카드입니다. 네 칸이 순서대로 있습니다.

| 칸 | 뜻 | 누르면 |
|---|---|---|
| **팔 때** | 보유 종목 종가가 {{exitLookback}}일 최저가 이하로 마감했습니다 | 안 눌림 — [터틀 정리](#cleanup) 화면에서 처리 |
| **다시 살 때** | 감시 중인 관심종목 종가가 {{entryLookback}}일 최고가 위로 마감했습니다 | [재매수 계산기 열기 →] |
| **추가 매수** | 재매수한 종목이 불타기 기준가에 도달했습니다 | [재매수 계산기 열기 →] |
| **손절선 확인** | 재매수한 종목의 증권사 예약 손절가를 점검할 차례입니다 | 안 눌림 — 읽기 전용 |

각 줄에는 "왜 떴는지" 한 줄이 붙습니다. 예: "{{exitLookback}}일 최저가 51,200원 이하로 마감 (종가 50,800원)".

- 칸이 전부 비어 있으면 **오늘 할 일 없음 — 규칙상 보유 유지** 라는 문구가 보입니다. 빈 화면이 아니라 정상 상태입니다.
- 카드 위쪽에 **대기 자금**(파킹 중인 현금) 금액이 항상 보입니다.
- 계좌 축소가 켜져 있고 지금 적용 중이면 [계좌 축소 적용 중] 배지가 붙습니다.
- 시세를 못 가져온 종목이 있으면 [확인 필요 N종목] 줄이 생기고, 눌러서 펼치면 사유가 보입니다.
- 시세를 불러오는 중에는 "시세를 불러오는 중입니다…"가 잠깐 보입니다.
- 판정에 쓰는 종가는 **장이 끝나고 그날 종가가 확정된 뒤**의 값입니다. 한국·일본 종목은 장 마감 약 30분 뒤(오후 4시경)부터, 미국 종목은 장 마감 약 1시간 뒤(미국 동부 오후 5시경 — 한국 시간으로는 이튿날 아침 6~7시경)부터 그날 종가를 씁니다. 그 전에는 직전 거래일 종가 기준이며, 아직 끝나지 않은 장중 가격으로는 판정하지 않습니다.

<a id="sell"></a>
## ③ 팔 때 — 증권사에서 판 다음 앱에 기록

1. [팔 때] 칸에 뜬 종목을 증권사 앱에서 실제로 매도합니다.
2. 큰 종목은 [터틀 정리](#cleanup) 화면에서 [팔았음 기록]을 누릅니다. 작은 종목은 홈 카드에서 바로 처리하지 않고, 역시 [터틀 정리] 화면에서 모아 처리합니다.
3. 매도 창에서 실제 체결일·체결가·수량을 입력하고 [매도]를 누릅니다.
4. 화면 아래 체크박스 `"다시 살 때" 감시 명단에 추가`가 기본으로 켜져 있습니다. 켜 두면 이 종목이 나중에 {{entryLookback}}일 최고가를 다시 넘을 때 재매수 후보로 알려 드립니다. **전량 매도일 때만 적용됩니다.**
5. 저장하면 그 종목이 자동으로 **"다시 살 때" 감시 명단**에 들어갑니다. 사용자가 누른 저장 버튼과 함께 기록되므로, 보이지 않는 자동 저장이 아닙니다.

> 참고: 이 체크박스의 안내 문구 속 일수는 설정({{entryLookback}}일)을 그대로 따라갑니다 — 예전에는 "55일"로
> 화면에 고정돼 있어 {{entryLookback}}을 바꾸면 문구와 실제 판정이 어긋났지만, 지금은 고쳐졌습니다.

**"현재 재진입 기준선"이 뭔가요?** 팔 때 칸 종목 아래에 "현재 재진입 기준선 ○○원 — 최근 확정 종가 대비 +○%"가 함께 보입니다. 팔고 난 뒤 이 종목을 다시 사라고 알려 드리려면 종가가 넘어야 하는 가격(직전 {{entryLookback}}일 최고가)을 지금 기준으로 미리 보여 주는 참고 정보입니다. 기준선은 매일 바뀌고(오래된 고점이 빠지면 내려갈 수도 있습니다), 실제로 다시 사는 가격은 아직 정해진 것이 아니며, 이 줄 때문에 판정이 바뀌지는 않습니다.

<a id="rebuy"></a>
## ④ 다시 살 때 / 추가 매수 — 재매수 계산기

[터틀 오늘 할 일] 카드의 **다시 살 때** 또는 **추가 매수** 줄을 누르면 계산기 창이 열립니다.

제목은 **재매수 — 다시 살 때** 또는 **재매수 — 추가 매수(불타기)** 입니다.

계산기 위쪽 회색 상자에 네 가지가 보입니다.

1. **N ({{exitLookback}}일과 별개 — 20일 ATR)**: 이 종목이 하루에 보통 얼마나 움직이는지.
2. **변동성**: 잔잔함 / 보통 / 출렁임 큼.
3. **손절 예약가(증권사)**: 마지막 체결가 − {{stopMultipleN}}N. 증권사에 이 가격으로 예약주문을 겁니다.
4. **다음 불타기가**: 여기서 더 오르면 다음 유닛을 사는 가격.

숫자 예시(계획서 예시): 50,000원에 사고 N이 1,500원이면, "이 종목은 하루 평균 1,500원(3%)씩 움직입니다. 그래서 손절가를 3,000원(6%) 아래인 47,000원으로 잡았습니다." 불타기 간격이 2R이면 다음 불타기가는 50,000 + 6,000 = 56,000원입니다.

아래 폼에서 **체결일·체결가·수량**을 실제로 산 값으로 입력합니다(기본값은 계산된 값이지만 고쳐도 됩니다). 체결가를 고치면 손절가·다음 불타기가도 같은 N으로 다시 계산됩니다.

- 매수 순서: **① 증권사에서 먼저 산다 → ② 증권사에 손절 예약주문을 건다 → ③ 앱에서 [샀음 기록]을 누른다.**
- [샀음 기록]을 누르면 매수 기록과 유닛 기록이 함께 저장됩니다. 실패하면 사유가 뜨고 입력값은 지워지지 않습니다.
- 매수 금액이 {{minOrderKRW}}원 미만이면 "매수 금액이 최소 주문 금액 미만입니다"가 뜨고 재매수가 생략됩니다.
- 이 종목이 이미 {{maxUnitsPerPosition}}유닛을 다 채웠으면 "이 종목의 유닛 한도(불타기 횟수)에 도달했습니다"가 뜹니다.

<a id="stopcheck"></a>
## ⑤ 손절선 확인 칸의 의미

[터틀 오늘 할 일]의 **손절선 확인** 칸은 재매수한 종목 중 "보유 유지" 또는 "추가 매수" 상태인 것만 보여줍니다.

이 칸은 **누를 수 없습니다.** 할 일은 앱 밖에 있습니다 — 증권사 앱을 열어 그 가격으로 손절 예약주문이 실제로 걸려 있는지 눈으로 확인하는 것입니다. 문구 예시: "증권사 손절 예약 48,800원이 걸려 있는지 확인하세요 (청산선 49,000원)."

같은 종목이 **추가 매수** 칸과 **손절선 확인** 칸에 동시에 뜰 수 있습니다. 두 칸의 문구는 일부러 다르게 씁니다 — 추가 매수 칸은 "왜 더 사는지", 손절선 확인 칸은 "예약이 걸려 있는지 점검하라"는 뜻입니다.

<a id="cleanup"></a>
## ⑥ 터틀 정리 화면

더보기 → [터틀 정리](예전 이름 "대청소"). 지금 청산선 아래에 있는 종목만 모아 보여줍니다.

- **작은 종목(총자산 1% 미만) — 일괄 처리**: 체크박스로 골라 [전체 선택]한 뒤, 아래 [팔았음 기록] 버튼 하나로 한꺼번에 처리합니다. 체결가는 현재가로 자동 기록되고, 실제 체결가가 다르면 나중에 매도 기록에서 고칠 수 있습니다.
- **큰 종목 — 개별 결정**: 종목마다 [팔았음 기록] 또는 [이번엔 보류]를 고릅니다. [이번엔 보류]를 누르면 보류 사유(필수) 입력칸이 열리고, 적은 뒤 [기록]을 누릅니다.
- 종목마다 "현재 재진입 기준선"(팔고 난 뒤 다시 사라고 알려 드리려면 종가가 넘어야 하는 가격)이 한 줄로 함께 보입니다. 기준선은 매일 바뀌고 실제로 다시 사는 가격은 아직 정해지지 않았다는 점은 위 ③ 팔 때 설명과 같습니다.
- 같은 종목을 2번 넘게 보류하면 [규칙과 다르게 N번 보류] 배지가 빨간 경고색으로 붙습니다.
- 위쪽에 접힌 **해외주식 양도세 통산** 패널이 있습니다(배지: "추정 · 세무조언 아님"). 올해 실현 해외손익과 지금 팔면 생길 손익을 합쳐 대략의 세금을 참고로 보여줍니다. 확정 판단은 세무 전문가와 상의합니다.
- 청산선 아래 종목이 하나도 없으면 "지금 청산선 아래에 있는 종목이 없습니다."가 보입니다.

<a id="newstock"></a>
## ⑦ 새 종목을 사고 싶을 때

터틀은 지금 보유·감시 중인 종목만 자동으로 봅니다. 새 종목을 터틀에 넣고 싶으면 사람이 먼저 골라야 합니다.

1. **관심종목** 탭에서 종목을 추가합니다(아직 없다면).
2. 그 종목 줄의 ⋯ 메뉴에서 [터틀 후보 지정]을 누릅니다. 이름 옆에 🐢 표시가 붙습니다.
3. 그때부터 이 종목도 [터틀 오늘 할 일]의 감시 대상입니다. 종가가 {{entryLookback}}일 최고가를 넘으면 **다시 살 때** 칸에 뜹니다.
4. 재매수 계산기를 열어 수량·손절가를 확인하고, 증권사에서 산 뒤 [샀음 기록]을 누릅니다.

여러 종목을 한꺼번에 지정하려면 **보유자산** 탭에서 종목을 체크 → [일괄 변경] → [🐢 터틀 후보 등록]을 누릅니다.

취소하려면 같은 ⋯ 메뉴에서 [터틀 후보 해제]를 누릅니다.

<a id="settings"></a>
## ⑧ 설정 '터틀 규칙'

더보기 → 설정 → [터틀 규칙] 섹션. 모든 항목 옆에 [원조] 또는 [조정] 배지가 붙습니다.

- [원조] = 1980년대 터틀 트레이딩 원래 규칙과 같은 값.
- [조정] = 이 앱이 현물(빚 없는) 계좌에 맞게 바꾼 값.

값을 바꾸면 그 아래 바로 과거 검증 성적 한 줄이 보입니다. 계산이 새로 도는 것이 아니라, 미리 검증해 둔 문장을 보여주는 것입니다.

| 항목 | 기본값 | 배지 | 바꿀 수 있는 범위 |
|---|---|---|---|
| 다시 살 때(재진입) — 직전 N일 최고가 | {{entryLookback}}일 | 원조 | 20~100일 |
| 팔 때(청산) 방식 — 최저가 채널 | {{exitLookback}}일 최저가 | 20일이면 원조 | [최저가 채널]/[이동평균]/[ATR 추적선], 10~55일 |
| 팔 때(청산) 방식 — 이동평균 대안 | {{maPeriod}}일 이동평균 | 조정 | 5~200일 |
| 팔 때(청산) 방식 — ATR 추적선 대안 | {{atrTrailMultiple}}배(ATR20 기준) | 조정 | 1.5~5배 |
| 손절 배수(재매수분) | {{stopMultipleN}}×N | 원조 | 1.5~3 |
| 유닛당 위험 %(관리자산 대비) | {{riskPerUnitPct}}% | 원조 | 0.25~1% |
| 종목당 최대 유닛 | {{maxUnitsPerPosition}}유닛 | 원조 | 1~4유닛 |
| 불타기 간격 | {{pyramidSpacing}} | [2R]이면 조정, [½N]이면 원조 | [2R(강의식 기본)]/[½N(원조)]/[직접 입력] |
| 추가 매수(불타기) 금액 배수 | 최초 유닛의 {{pyramidSizeMultiplier}}배 | 조정 | 1배 / 0.5배 |
| 종목당 한도(4유닛 기준) | {{positionCapPct}}% | 조정(필수) | 5~25% |
| 전체 위험 한도 | {{maxTotalRiskPct}}% | 원조 | 12~24% |
| 계좌 축소(드로다운 감쇄) | {{drawdownScalingEnabled}} | 꺼짐이면 조정 | 켜기/끄기 |
| 최소 주문 금액 | {{minOrderKRW}}원 | 조정 | 자유 입력(원 단위) |

**청산 방식**을 [최저가 채널]로 두고 일수를 10일 미만으로 바꾸려 하면 저장 자체가 막힙니다("10일 미만은 저장할 수 없습니다"). 10~19일은 저장은 되지만 "아직 이 종목군으로 따로 검증되지 않았습니다" 경고가 붙습니다.

**계좌 축소**를 켜면 그 아래 [지금 관리자산(…)으로 기준 정하기] 버튼으로 기준 자산을 정할 수 있습니다. 기준을 정한 지 1년이 넘거나 1월이 되면 홈 카드와 이 화면 둘 다에 "기준 자산을 새로 정하세요" 안내가 붙습니다.

**적용 범위**: 가족(유선) 계정은 항상 제외됩니다(고정, 여기서 바꿀 수 없음). 그 아래에서 카테고리별·종목별로 추가 제외를 고를 수 있습니다.

값을 바꾼 뒤 [저장]을 누릅니다(저장 전에는 반영되지 않습니다). 실수로 바꿨다면 [원조 기본값으로 되돌리기]를 누릅니다 — 단, 계좌 축소 기준 자산은 그대로 남습니다(되돌리기 대상이 아닙니다).

<a id="kakao"></a>
## ⑨ 카톡 알림 종류

설정 → [카카오톡 알림] 섹션. 1회 설정 방법은 [카카오톡 알림 설정 가이드](카카오톡_알림_설정가이드.md)를 따로 봅니다. 여기서는 터틀 알림의 종류만 설명합니다.

| 이모지 | 뜻 |
|---|---|
| 🟠 | 재매수 종목이 손절가 아래로 마감 — "손절 이탈" |
| 🔵 | 종목이 청산선 아래로 마감 — "팔 때" |
| 🔺 | 감시 종목이 {{entryLookback}}일 최고가를 넘었거나("다시 살 때"), 재매수 종목이 불타기 기준가에 닿음("추가 매수") — **같은 아이콘을 두 가지 뜻으로 씁니다.** 메시지 맨 앞 대괄호(`[팔 때]`처럼)로 구분합니다 |
| 📋 | 아침 요약(오늘 할 일 전체) |

발송 시점:

- **시장별 마감 확정 후 1회**: 팔 때·다시 살 때·추가 매수·손절 이탈 판정.
- **아침 요약 1회**: "오늘 할 일" 종목명과 건수만.
- 매매 계획(TradePlan)의 손절선·익절선·불타기선 알림과 **하루 발송 상한(8건)·정숙시간(00:00~07:00 KST)·요약 묶음**을 그대로 공유합니다.
- 같은 종목·같은 신호·같은 날은 한 번만 옵니다.

문구 예시: "🔵 [팔 때] 오뚜기 — {{exitLookback}}일 최저가 51,200원 이하로 마감 (종가 50,800원)\n보유 10주 매도 검토 후 앱에서 [팔았음 기록]하세요."

<a id="faq"></a>
## ⑩ 자주 묻는 질문

**Q. 왜 익절선이 없나요?**
A. 터틀은 "얼마나 벌었나"가 아니라 "추세가 꺾였나"만 봅니다. 오를 때는 계속 들고 가다가, 청산선 아래로 마감하면 그때 팝니다. 익절선(정해진 이익에서 절반 매도)은 매매 계획(TradePlan) 기능에만 있고, 터틀에는 없습니다.

**Q. 왜 손실 중인 종목도 "보유 유지"라고 하나요?**
A. 터틀은 매수가·손익률이 아니라 **청산선(가격)만** 봅니다. 손실 중이어도 종가가 청산선 위에 있으면 규칙상 계속 보유합니다. 반대로 이익 중이어도 청산선 아래로 마감하면 팔라고 뜹니다.

**Q. 종가가 청산선과 같으면 왜 벌써 "팔 때"인가요?**
A. 판정은 "이하"입니다(같아도 포함). 청산선에 정확히 닿는 것도 청산 신호로 봅니다 — 애매하게 두면 판단이 늦어지기 때문입니다.

**Q. 가족(유선) 계정은 어떻게 되나요?**
A. 터틀은 가족 계정을 항상 제외합니다(설정에서 끌 수 없는 고정값). 화면 위 계정 선택에서 "유선"·"통합"을 봐도 터틀 판정 자체는 항상 원종(본인) 자산만 대상입니다.

**Q. 숨긴 메뉴나 예전 신호를 다시 보고 싶어요.**
A. 두 가지가 다릅니다.
- **구루 신호 카드·참고 지표(리스크 매트릭스/과열)·알림 브리핑 자동 팝업**: 설정 → 표시 설정 → 신호 표시 → [기존 신호 보기] 토글을 켜면 한 번에 복원됩니다. 화면 표시만 바뀌고 계산·발화는 그대로입니다.
- **더보기 메뉴의 매매 계획 세우기·AI 어시스턴트·투자 가이드·연구실 · 신호 리플레이**: 이건 설정 화면 토글이 없습니다. 메뉴 목록에서만 빠져 있고 기능 자체는 남아 있어, 복원하려면 코드(`constants/moreMenuVisibility.ts`)를 고쳐야 합니다 — 필요하면 요청하세요.

**Q. 신호가 하나도 안 떠요.**
A. 먼저 [터틀 오늘 할 일] 카드의 [확인 필요 N종목] 줄을 펼쳐 시세를 못 가져온 종목이 있는지 봅니다. 관심종목에 🐢 표시가 없으면 감시 대상이 아니므로 신호도 없습니다. 설정의 적용 범위에서 그 종목이나 카테고리가 제외돼 있지 않은지도 확인합니다.

<a id="limits"></a>
## ⑪ 알아둘 대가·한계

- **수익이 줄 수 있습니다.** 검증 기준으로 최종 자산이 그냥 보유의 약 70~82%였습니다. 터틀의 목적은 돈을 더 버는 것이 아니라 **큰 손실을 막는 것**입니다.
- **최대 하락폭**은 선택한 설정으로 약 −20%였습니다(그냥 보유는 약 −27.5~−31%).
- **휩쏘**가 생깁니다 — 팔았다가 곧 다시 사는 일이 종목당 평균 약 1회 있었습니다. 매매마다 세금·수수료가 붙습니다.
- **금·은·채권 ETF**는 전부 적용을 선택했지만, 검증상으로는 이런 자산을 터틀에서 빼는 편이 방어(최대 하락폭)와 위험조정수익 모두 더 나았습니다. 설정의 적용 범위에서 카테고리 제외로 바꿀 수 있습니다.
- **검증의 한계**: 현재 보유 종목만 봤고(생존 편향), 과거 비중은 가상이며, 세금 통산은 반영하지 않았습니다.
- **시세 데이터**: 무료 시세 기반이라 일부 종목이 늦게 갱신될 수 있습니다. 오래된 시세면 "다시 살 때"·"추가 매수" 판단을 보류합니다.
- **카톡 알림**: 발송 정밀도는 ±15분이고, 카카오 토큰 갱신에 의존합니다. 카톡은 손절 체결을 보장하지 않습니다 — 증권사 예약주문이 먼저입니다.
- 자세한 검증 수치와 방법론: `docs/PLAN_터틀중심_앱재정비_260925.md` §3.3·§7, `docs/backtest/REPORT_2차_포트폴리오_터틀_260925.md`.

투자자문이 아닙니다. 실제 투자 결정과 주문의 책임은 사용자에게 있습니다.
